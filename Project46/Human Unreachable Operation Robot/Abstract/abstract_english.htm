ABSTRACT

           Human Unreachable Operation Robot : HUOR have an idea from limit of human ability to work. Especially, limit of human body that can protect himself from just some environment. because this reason that we decide to develop the robot that can be done those works. well, this robot is designed for 2 mobility system .there are robot arm, wireless camera sending VDO signal to the controller and using COM 86 development toolkit as CPU. Using C language to control Semi-automatic Machine.

          According to infrastructure and controlling circuit of it with high flexibility. It means that next generation developer can bring this idea to develop controlling program with more complex including developing with AI to make them efficiency perform works as we want.
