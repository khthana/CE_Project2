ABSTRACT

 

This project is create interface box for use to interface between keyboard of computer and mobile. This interface box will divide two parts . The part of input for use to translate mobile. This interface box will divide two parts . The part of input for use two micro controller and equipment such as RAM and LCD. LCD with display when we type the message . The part of  interface with external equipment. It has port for interface. Input will us use PS2 port for interface with keyboard and output will use serial port to interface with data link of mobile The part of main board will divide two parts. The part of input will write form C language because it able to fix level of bit easy. The part of main program which control will write from Basic language because it able to easy control external equipment.
