การพัฒนาเว็บเซอร์วิสบนระบบฝังตัว

 

นายธเนศ  ชูวิเศษวณิชย์     43010175

นายธีรยุทธ  สุทธิสุวรรณ   43010189

ผศ.อภิเนตร  อูนากูล    อาจารย์ที่ปรึกษา

ปีการศึกษา 2546

 

 

บทคัดย่อ

 

                ในปัจจุบันการสื่อสารระหว่างแอพพลิเคชั่นผ่านออบเจ็กต์ระยะไกล (Remote Procedure Call) ได้รับการพัฒนาขึ้นด้วยเทคโนโลยีเว็บเซอร์วิส (Web Service) ที่นำเสนอแนวคิดในการกำหนดมาตรฐานการเชื่อมต่อระหว่างแอพพลิเคชั่น เพื่อให้ระบบที่มีความแตกต่างกันสามารถติดต่อสื่อสารถึงกันได้  โดยอาศัยข้อดีของโปรโตคอลเอชทีทีพี (HTTP Protocol) ที่มีความนิยมใช้กันอย่างแพร่หลาย  และกลไกในการแลกเปลี่ยนข้อมูลผ่านทาง SOAP (Simple Object Access Protocol) ที่ใช้โครงสร้างของ XML Language ที่ใช้ในการนิยามความหมายของข้อมูล

                การนำเอาเว็บเซอร์วิสมาพัฒนาบนระบบฝังตัวจะช่วยทำให้อุปกรณ์มีความสามารถในการเชื่อมต่อกับอุปกรณ์ต่างๆ และความสามารถในการเชื่อมโยงข้อมูลที่ใช้ในการควบคุมอุปกรณ์ได้อย่างมีประสิทธิภาพสูงสุด จึงได้เกิดโครงงานในปีการศึกษา 2545 ที่นำเสนอซอฟต์แวร์บนระบบฝังตัวที่ช่วยในการจัดการเอกสารที่มีรูปแบบตามมาตรฐานซิมเปิ้ล ออบเจ็กต์โปรโตคอล และเป็นเซิร์ฟเวอร์ที่ให้บริการเซอร์วิสกับอุปกรณ์ต่างๆได้ และในโครงงานนี้เป็นการพัฒนาซอฟต์แวร์ดังกล่าวต่อเนื่องจากเดิม เพื่อเพิ่มประสิทธิภาพและความสามารถในการทำงานให้เหมาะกับการนำไปใช้งานจริงต่อไป

                ปริญญานิพนธ์ฉบับนี้จัดทำขึ้นเพื่อวัตถุประสงค์ในการนำเสนอแนวความคิด ทฤษฏีและหลักการในการพัฒนาเว็บเซอร์วิสบนระบบฝังตัวที่สามารถเป็นเซิร์ฟเวอร์ที่ให้บริการเซอร์วิส
