เนื่องจากโครงงานนี้ เป็นโครงงานในเชิง Web Application
ดังนั้น จึงไม่มีเรื่องของการ Execute ไฟล์เกิดขึ้น (เป็นเรื่องของ HTML, PHP ที่ไม่เกี่ยวข้องกับไฟล์ EXE)
ถ้าหากเราต้องการทดสอบการใช้งาน เราจำเป็นต้องติดตั้งสภาวะแวดล้อมทุกอย่างให้สมบูรณ์ จึงจะสามารถเรียก Web Application นี้ได้


รายละเอียดการติดตั้ง ตลอดจนไฟล์ และโปรแกรมที่เกี่ยวข้องนั้น
กรุณาอ่าน "คู่มือโปรแกรมเมอร์"  และ "คู่มือการใช้งาน"
