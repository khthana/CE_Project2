บทคัดย่อ

เนื่องมาจากที่สภาพการจราจรในปัจจุบันมีปัญหาการจราจรที่ติดขัดและมีแนวโน้มที่จะทวีความรุนแรงเพิ่มมากขึ้นเรื่อยๆ โดยเฉพาะในเมืองใหญ่ๆ ซึ่งเกิดจากการเพิ่มขึ้นของประชากร ซึ่งกลุ่มผู้ดำเนินโครงงานได้แลเห็นถึงปัญหาข้อนี้จึงได้พยายามสร้างระบบตรวจสอบสภาพการจราจร(Traffic Checking System) ให้มีสามารถนับปริมาณรถบนท้องถนน ตรวจสอบความเร็วบนท้องถนน และนำข้อมูลที่ได้ไปทำการหาความหนาแน่นบนท้องถนน โดยการทำงานของระบบจะทำการรับภาพเข้ามาเป็น Input มาผ่านขบวนการประมวลผลภาพ และนำมาทำการวิเคราะห์หาจำนวนรถ ความเร็วของรถและความหนานแน่นของรถ โดยที่ระบบตรวจสอบสภาพการจราจรนี้สามารถทำงานได้ 2 แบบ คือทำงานในส่วนของเรียลไทม์ (Real-time) รับภาพจากกล้องวิดีโอเข้ามาประมวลในขณะนั้นเลยและการทำงานในส่วนของออฟไลน์ (Offline) ซึ่งจะนำภาพที่มีการบันทึกไว้ก่อนมาทำการประมวลผล

ABSTRACT

Due to traffic jam troubles which have been increasing to be serenely. We would like to resolve these problems. So we have developed the Traffic Checking System. It’s the system that has been designed to be able to counting the vehicles and checking the speed of vehicles as inputs to analyses the traffic. The input can be both receive via a camera that is connected via USB port, and stream of data from AVI file. The technique that we brought develop the process of system is Image Processing
