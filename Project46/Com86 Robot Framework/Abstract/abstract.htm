Abstract

            At this present time, the use of Robot is widely used in many areas and it is very interesting.  However, there are some limits for building a robot, mostly are the lack of knowledge and understanding. Building a robot, the high knowledge of hardware and software is necessary. And as the ability of the robot nowadays is much created and developed, to support it, the micro-controller, which can support the higher evolution, is introduced to use in building the robot. Then the higher ability is relevant to the harder study of working of the devices of the robot also. Thus, the development of the robot is assumed that it is still difficult.

            So, the idea of this project is created to develop the assistant program for using the robot, and the order set for controlling and directing the devices for the Framework and Engine for com86 Robot. It will help smooth the complicated of the set up and program writing of the robot which is easier to build a robot and it is convenient to adapt in other work in the future.
