บทคัดย่อ

               

การพัฒนาเกมส์บนมือถือ มีลักษณะเป็นเกมส์ออนไลน์ 2 มิติ เป็นการพัฒนาโปรแกรมเพื่อความบันเทิง โดยใช้ภาษา J2ME (Java 2 Micro Edition) ในส่วนของ Client และใช้ภาษา ASP ในส่วนของ Server   สำหรับการติดต่อระหว่าง Client กับ Server นั้นใช้ Http connection ในการติดต่อโดยผ่านโปรโตคอล GPRS

                ลักษณะของเกมส์เป็นเนื้อเรื่องของวรรณคดีไทยเรื่อง พระอภัยมณี ซึ่งจะมีตัวละครที่เป็นตัวเอกหลายตัวเช่น พระอภัยมณี ,ศรีสุวรรณ ,แก้วเกสา ,นางเงือก เป็นต้น โดยตัวผู้เล่นจะสวมบทบาทเป็นตัวละครนั้น เพื่อดำเนินตามเนื้อเรื่องในเกมส์ที่แตกต่างกันในบางช่วงของเกมส์  หลังจากนั้นตัวละครทุกตัวก็จะดำเนินเนื้อเรื่องตามปกติ

                โดยเกมส์นี้นั้นนอกจากจะให้ความบันเทิงและผ่อนคลายกับผู้เล่นแล้ว ยังทำให้ผู้เล่นได้มีความรู้ความเข้าใจในวรรณคดีไทย และเป็นการอนุรักษ์วรรณคดีไทยแก่คนรุ่นหลังอีกด้วย
