บทคัดย่อ

                ปัจจุบันเอกสารสื่อดิจิตอลถูกใช้กันอย่างแพร่หลายทางอินเทอร์เน็ต           ซึ่งมีการนำเอกสารสื่อดิจิตอลของผู้อื่นไปใช้งานโดยไม่ได้รับอนุญาต โครงงานนี้สามารถที่จะทำให้เจ้าของเอกสารสื่อดิจิตอลสามารถที่จะทำให้เอกสารสื่อดิจิตอลของตนเองนั้นมีลิขสิทธิ์ที่สามารถตรวจสอบได้ โดยทำการใส่ภาพลายน้ำลงไปในเอกสารสื่อดิจิตอล เพื่ออ้างสิทธิ์ได้ว่าเอกสารดังกล่าวเป็นของผู้สร้างเอกสารนั้น ในกรณีที่มีผู้ทำการละเมิดลิขสิทธิ์นั้นได้

                โครงงานนี้เป็นการนำภาพลายน้ำมาทำการรวมกับเอกสารสื่อดิจิตอลโดยที่ เมื่อทำการรวมกันแล้วไม่สามารถสังเกตเห็น ภาพลายน้ำนั้นและเอกสารสื่อดิจิตอลต้นแบบก็ไม่มีความผิดเพี้ยนไปจากเดิม ถึงแม้เอกสารสื่อดิจิตอลที่ทำการฝังลายน้ำลงไปแล้วถูกโจมตีอย่างไรก็ตาม เช่น ถูกลดขนาด ถูกปรับความเข้มของสี หรือถูกตัดไปใช้เพียงส่วนหนึ่งส่วนใดก็ตาม โครงงานนี้ก็ยังสามารถที่จะสามารถตรวจสอบลายน้ำนั้นได้ โดยในโครงงานนี้ใช้หลักการทำลายน้ำในโดเมนความถี่ ซึ่งใช้เทคนิคของ DCT(Discrete Cosine Transform)

ABSTRACT

Nowadays the documents are used by people for communications on the internet. Sometime the documents are used by which do not have the permission form owner document. This project can do the copyright and checks the permission form the owner document that needs to protect the document by inserting copyright image to original image; the owner who creat the document can.

This project add up the original image with copyright image, when they are added the copyright image which is the invisible image. The copyright image and original image do not change the shape. Although, the watermark image is attacked by attacker such resize technique, color attack technique or some part cutting. This project can check the owner of image. We used the frequency domain technique applied to this project and used the Discrete Cosine Transform (DCT) for calculate the high frequency and the key is inserted to copyright image.
