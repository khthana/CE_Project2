ABSTRACT

                This thesis is about to study how to design and building up the heart pulse rate detector and recorder instrument that user can take it everywhere the purpose for detecting heart pulse rate and keep recording the value in the memory for doctor reorganization how the userís health, This instrument is not only recording the value of heart pulse rate but also showed that value to user by display, feature more it can alarm user if userís heart pulse rate is over than the base rate that it should be by display and sound alarm, this thesis is including the software to work with the instrument that could be help doctor reorganization
