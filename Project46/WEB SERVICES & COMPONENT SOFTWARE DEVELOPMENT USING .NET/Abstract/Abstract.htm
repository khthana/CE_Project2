บทคัดย่อ

 

          ปัจจุบันทิศทางของเทคโนโลยีถูกกำหนดค่อนข้างแน่ชัด ให้มุ่งไปสู่ ดอทเน็ต ( .Net) และ เว็บเซอร์วิส (Web Services) ซึ่งถือเป็นอีกหนึ่งเทคโนโลยีบนโลกอินเตอร์เน็ตที่กำลังได้รับความสนใจเป็นอย่างยิ่ง เพราะไม่ว่าจะเป็นบริษัทเอกชนหรือหน่วยงานของรัฐบาลทั่วโลก ต่างก็ให้การสนับสนุนเทคโนโลยีนี้เป็นอย่างมาก จึงทำให้เว็บเซอร์วิส ก้าวเข้ามามีบทบาทอย่างมากในการพัฒนาโปรแกรมสมัยใหม่ กล่าวคือ เทคโนโลยีนี้จะช่วยขยายขีดความสามารถของอินเทอร์เน็ต

                เว็บเซอร์วิส เป็นพื้นฐานสำคัญของการบริการใหม่ๆ ในลักษณะที่ต้องการเชื่อมโยงระบบสารสนเทศที่มีความแตกต่างเข้าด้วยกันอย่างอัตโนมัติ เช่น การพาณิชย์อิเล็กทรอนิกส์ระหว่างธุรกิจกับธุรกิจ

                โดยปริญญานิพนธ์นี้จะอธิบายถึงรายละเอียดของเว็บเซอร์วิส พร้อมทั้งได้จัดทำระบบขึ้นมาระบบหนึ่ง ซึ่งเป็นเว็บเซอร์วิสที่ให้บริการ (Services) เกี่ยวกับการซื้อขายบ้าน และแบบบ้าน  และยิ่งไปกว่านั้น ก็ยังมีเนื้อหาที่เกี่ยวข้องกับภาษาคอมพิวเตอร์ที่ใช้สร้างรูปเสมือนจริงเป็นรูปภาพกราฟิก 3 มิติ หรือที่เรียกว่า VRML (Virtual Reality Modeling Language) ซึ่งจะช่วยให้ลูกค้าที่เข้าไปใช้บริการดูบ้าน ได้เห็นราวกับว่าได้ไปเดินดูด้วยตัวเอง
