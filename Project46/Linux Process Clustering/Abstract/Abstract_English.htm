ABSTACT

 

                This thesis is to build a cluster system on Linux RedHat 9.0 Operating System in order to implement on the large computer system which need high calculation. The performance of this system is equal or above the super computer which high cost. Using many PCs that can buy in lower price. The process is to separate the task or process into sub-process and then send each sub-process to each PCs to compute them. Then they will return result in the short period of time. It is very useful and is the another choice for company which having limit of budget
