บทคัดย่อ

 

 ปัจจุบันระบบเครือข่ายแลนแบบไร้สายเป็นที่นิยมใช้กันมากขึ้น เนื่องจากช่วยลดข้อจำกัดหลายประการของระบบเครือข่ายแลนแบบใช้สาย เช่น การติดตั้งทำได้รวดเร็วและง่าย     ความยืดหยุ่นในการติดตั้ง  ความสะดวกในการเคลื่อนย้าย และเนื่องจากเครือข่ายแลนแบบไร้สายใช้คลื่นความถี่วิทยุในการสื่อสารถึงกันแทนการใช้สายนำสัญญาณนั้นการออกแบบเครือข่ายแลนแบบไร้สาย   จึงจำเป็นต้องมีการออกแบบให้เครื่องคอมพิวเตอร์ที่อยู่ในเครือข่ายสามารถรับหรือส่งข้อมูลถึงกันได้อย่างต่อเนื่องและไม่มีการสูญเสียของข้อมูล    ซึ่งทำให้การออกแบบเครือข่ายไร้สายนั้นมีความซับซ้อนและต้องใช้เวลาในการออกแบบพอสมควร เนื่องจากมีตัวแปรหลายอย่างที่จะส่งผลในการรับส่งข้อมูลกันระหว่างเครื่องภายในเครือข่าย เช่น ค่าความสูญเสียในสายนำสัญญาณ, ค่ากำลังเอาท์พุท, ระยะห่างระหว่างตัวแอคเซสพอยท์กับตัวไคลแอนท์ โดยซอฟท์แวร์ช่วยออกแบบเครือข่ายแลนไร้สาย สามารถคำนวณหาค่าตัวแปรต่างๆเหล่านี้ได้โดยอัตโนมัติ ซึ่งจะช่วยผู้ออกแบบเครือข่ายให้มีความสะดวกในการออกแบบมากยิ่งขึ้น

โครงงานนี้ได้อำนวยความสะดวกให้ผู้ออกแบบในการคำนวณหาค่าพารามิเตอร์ที่สำคัญที่ใช้ในการออกแบบ เช่น ค่าความสูญเสียในสายนำสัญญาณ, กำลังส่ง, เลือกสายอากาศที่เหมาะสมกับความถี่ที่ใช้และลักษณะโครงสร้างของตัวอาคาร ซึ่งโปรแกรมจะทำการคำนวณค่าพารามิเตอร์ต่างๆโดยอัตโนมัติ ทำให้ลดความผิดพลาดและสะดวกรวดเร็ว

ABSTRACT

 

               Wireless LAN system is widely used and considered more popular in computer networking recently. The wireless system is also known for simple, flexible  installation, and mobility. However, the quality of signal among server and client computers can be affected by cable loss, output power, and the range between access point and client computers. Therefore, the well system design which can eliminate those factors will be very importance for efficiently of  the wireless network.  The purpose of  this study is to develop computer software for designing Wireless LAN system that can optimize automatically for the value of cable loss, transmitter output power, and appropriate antenna.
