 บทคัดย่อ  
เอกซเอมแอลได้กลายเป็นมาตรฐานการส่งข้อมูลบนอินเตอรเน็ต, การส่งข้อมูลภายในเครือข่ายเดียวกัน ทั้งยังเป็นมาตรฐานในการส่งข้อมูลของเว็บเซอร์วิส (Web service) ที่เรียกกันว่า SOAP หรือแม้แต่ การทำ ธุรกิจบนอินเตอร์เน็ต (Ecommerce) ซึ่งข้อมูลที่นำมาแสดงเป็นก็เป็นเอกสารเอกซเอมแอล (XML Document) ดังนั้นจึงเห็นได้ว่าเทคโนโลยีของเอกซเอมแอลนั้นน่าสนใจอย่างมาก
ในเมื่อเอกสารเอกซเอมแอลถูกนำมาใช้บนธุรกิจบนอินเตอร์เน็ต ซึ่งเป็นที่รู้กันว่าข้อมูลเป็นสิ่งสำคัญมากดังนั้น จึงมีการคิดค้นการรักษาความปลอดภัยต่างๆขึ้นมามากมาย เช่น การเข้ารหัส (Encrytion), การพิสูจน์ตัวตน (Autentication) เป็นต้น ดังนั้น ระบบการจัดการการเข้าถึงเอกสารเอกซเอมแอล (Xml Access Control) ที่คิดค้นขึ้นมามีจุดประสงค์เพื่อความปลอดภัยเช่นเดียวกัน ซึ่งมีหน้าที่หลักสองประการด้วยกันคือ การพิสูจน์ตัวตนและการพิสูจน์สิทธิ (Athorization) ในการเข้าถึงเอกสารเอกสารเอกซเอมแอล เพื่อสร้างความปลอดภัยในการนำเสนอข้อมูลที่แตกต่างกันโดยมีกำหนดการกฎเข้าถึงเป็น(Access Rule)เป็นตัวระบุสิทธิในการทำงานต่างๆ นอกจากนี้ยังประยุกต์การแปลงข้อมูลจากฐานข้อมูลเชิงสัมพันธ์ (Relational Database) มาแปลงเป็นเอกสารเอกซเอมแอล ก่อนที่จะมีการตรวจสอบการเข้าถึง เพราะในความเป็นจริงการเก็บข้อมูลส่วนใหญ่จะเก็บอยู่ในรูปแบบฐานข้อมูลเชิงสัมพันธ์
ดังนั้น โครงงานนี้จึงนำแนวคิดระบบการจัดการการเข้าถึงเอกสารเอกซเอมแอล ไปประยุกต์ใช้กับการทำธุรกิจบนอินเตอร์เน็ต เพื่อให้เห็นถึงประโยชน์บางส่วนของการนำแนวคิดนี้ไปใช้งาน
 
 Abstract  
XML has become standard for transfering informations both on internet and intranet. It's also common for transfering informations on Web Service, called SOAP or even in Ecommerce. Information on display is also XML document. Then, XML technology is considered very interesting.
When XML document is used on internet's E-commerce, it is widely known that information is highly important. Various security systems have been made e.g. encryption and authentication for verification etc.. Likewise, XML Document access control application is invented for the same reason. Two main applications, authentication and authorization, are required prior to access for security purpose. For reaching different levels of informations, access rule is imposed to identify "right of way" in operating system. In addition, it can be modified from relational database to XML document prior to access as most of informations are kept as relational database.
For this project, XML document access is modified for E-commerce application on internet to demonstrate how part of this concept can be applied for practical use.
