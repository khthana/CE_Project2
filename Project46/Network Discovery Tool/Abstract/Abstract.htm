บทคัดย่อ

ในปัจุจบันนี้มีการใช้งานเครือข่ายการสื่อสารข้อมูลภายในองค์กรต่างๆเป็นไปอย่างแพร่หลายทั้งในด้าน สื่อสารข้อมูลภายในองค์กร และการสื่อสารข้อมูลระหว่างองค์กร ดังนั้นก็จะเป็นเรื่องยากสำหรับผู้ดูแลระบบ หรือผู้ที่ต้องการศึกษาระบบเครือข่ายนั้นๆ ว่ามีการวางระบบหรือมีการเชื่อมต่ออย่างไร ภายในองค์กรหรือระหว่างองค์กร

วิทยานิพนธ์นี้เป็นการนำเสนอ โครงการพัฒนาโปรแกรมสำรวจเครือข่าย (Network Discovery Tool) โดยตัวโปรแกรมนี้จะมองภาพรวมของระบบเครือข่าย จึงช่วยให้ผู้ใช้งานโปรแกรมมองเห็นภาพของระบบเครือข่ายได้ง่ายขึ้น และโครงการนี้จะนำเสนอเทคนิคต่างๆ ที่ใช้ในการรวบรวมข้อมูลของระบบเครือข่าย(Ping Sweep, Trace Route, NetStat, SNMP, Whois) ส่วนที่ใช้ในการจัดเก็บข้อมูล และส่วนที่ใช้ในการจัดการเพื่อนำเสนอผลบนโปรแกรม รวมถึงรายละเอียดในการพัฒนาโปรแกรม เพื่อให้ผู้ที่สนใจสามารถนำไปเป็นแนวทางในการพัฒนาเครื่องมือที่ใช้อำนวยความสะดวกในการจัดการเครือข่ายอื่นๆ เพื่อลดการนำเข้าโปรแกรมต่างๆจากต่างประเทศ

ABSTRACT

                Presently, Communication Network is applied widely in many organizations including both internal communication and external communication. Therefore, It is hard for administrator or anyone who wants study about network how to design the system or how to connect it?

                The thesis describes the Network Discovery Tool that this program will  look overview of network and it can help users to clarify the topology including describes the use of enumeration technique for gathering network information(Ping Sweep, Trace Route, NetStat, SNMP, Whois), storing database and information processing in order to display. Eventually, other developers will be able to continue this work efficiently in many different ways.
