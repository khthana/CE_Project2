บทคัดย่อ

               

                ปริญญานิพนธ์นี้นำเสนอการพันฒนาบราวเซอร์ที่สามารถโปรแกรมได้ [1, 2, 3] โดยอาศัยภาษา PythonCE บนเครื่อง PocketPC โดยบราวเซอร์ชนิดนี้ผู้ใช้สามารถโปรแกรมให้กระทำคำสั่งการสื่อสารหลากหลาย ได้แก่ การดาวน์โหลดหน้าเว็บ การรับส่งอีเมลล์ ฯลฯ และกระทำคำสั่งอื่นๆ ตามกำหนดเวลา นอกจากนั้นยังสามารถกระทำคำสั่งเพื่อตอบสนองกับเหตุการณ์ตามที่โปรแกรมไว้โดยผู้ใช้ในรูปคำสั่งสคริปต์ที่มีรูปแบบเป็น Event®Action ชุดคำสั่งสคริปต์ทั้งหมดนี้แท้ที่จริงเป็นชุดโปรแกรมคำสั่งในภาษา CL (Communication Language) ซึ่งพัฒนาขึ้นโดย วิศิษฏ์ หิรัญกิตติ และสุพัณณดา โชติพันธ์ [3] ดังนั้นส่วนประมวลผลคำสั่งของบราวเซอร์นี้จะเป็น CL Interpreter พัฒนาขึ้นโดย สุพัณณดา โชติพันธ์ ซึ่งเราได้นำมาดัดแปลงเพื่อใช้งานบนเครื่อง PocketPC อีกที

                ในปริญญานิพนธ์ฉบับนี้เราได้พัฒนา Environment ของบราวเซอร์ที่เป็นส่วนติดต่อด้วยกราฟฟิกส์กับผู้ใช้ทั้งหมด โดยเฉพาะส่วนอำนวยความสะดวกในการเขียนโปรแกรมคำสั่งสคริปในลักษณะการใช้ออร์แกไนเซอร์ ซึ่งผู้ใช้สามารถโปรแกรมคำสั่งที่ต้องการประมวลผลโดยอาศัยเวลาที่เลือกจากปฏิทินของออร์แกไนเซอร์ ซึ่งทำให้ง่ายต่อในการกำหนดเวลาให้กับคำสั่งที่บราวเซอร์จะกระทำ นอกจากนี้เรายังได้พัฒนาส่วนที่สนับสนุนบริการการติดต่อสื่อสาร ได้แก่ การเปิดหน้าเว็บ การส่งอีเมลล์ และการส่งไฟล์ผ่านโปรโตคอลเอฟทีพี ซึ่งเชื่อมโยงกับ CL Interpreter เพื่อช่วยประมวลผลคำสั่งที่เกี่ยวกับการสื่อสาร และส่วนของการจัดการโฟรไฟล์ที่ทำให้ผู้ใช้สามารถกำหนดรายละเอียดข้อมูลส่วนตัวสำหรับการติดต่อสื่อสารที่เป็นบริการต่างๆ

                         


Programmable Browser on Pocket PC

ABSTRACT

 

In this thesis we have proposed a development of the Programmable Browser [1, 2, 3] on a Pocket PC using PythonCE. With this browser the user can program the browser to do communication tasks such as downloading a web page, sending/receiving emails, as well as to do other computing tasks according to the time schedule. In addition, the user can program the browser to perform an action in response to a certain event by programming it with the script conditional command in the form Event®Action. All the programs submitted to and to be executed by the browser are in fact written in CL (Communication Language) developed by Hirankitti and Chotipanta [3]. Thus, the browser employs a CL interpreter, developed by Chotipanta and ported to PocketPC by us, to execute all the tasks we have given to it.

                In this thesis we have developed all the environment of the browser in a GUI manner, especially the part that helps the user program the browser to do tasks with ease by providing the user with an organizer-like interface where the user can select date and time from a calendar for a schedule to run a CL command.  Moreover, we have also developed many communication modules for opening web pages, sending emails, and sending files via the FTP protocol. These modules are employed by the CL interpreter to execute CL communication commands. Finally, we have developed a user-profile manger for the browser’s users to create their profiles. The profiles allow the users to provide their personal information useful for communication by various means.
