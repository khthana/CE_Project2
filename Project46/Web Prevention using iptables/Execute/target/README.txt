ก่อนการใช้งานโมดูลนี้

1. โมดูลนี้ใช้ได้เฉพาะกับ เคอร์เนลเวอร์ 2.4.23 ถ้าเป็นเวอร์ชั่นอื่น อาจจะต้องมีการ ใช้ออปชั่น -f ในการนำโมดูลนี้เข้าไปในเคอร์เนล หรือคอมไพล์ตัวโปรแกรมนี้ขึ้นมาใหม่

2. โมดูลนี้ใช้ได้กับไอพีเทเบิลเวอร์ชั่น 1.2.8 ถ้าเป็นเวอร์ชั่นจะต้อง คอมไพล์ใหม่เพื่อให้รองรับกับตัวที่เป็นแชร์ไลบรารี่

3. ในการคอมไพล์โมดูลที่เป็นแชร์ไลบรารี่ จำเป็นจะต้องคอมไพล์ในซอร์สของไอพีเทเบิล ซึ่งเราจะต้องไปแทรก เมกไฟล์ที่อยู่ในโฟลเดอร์ /iptables-1.2.8/extension/Makefile โดยวิธีการแทรกชื่อนั้นจะเอาเป็นชื่อของโมดูลที่ต้องการจะใช้งานเช่น ในที่คือ ipt_WEBDROP ก็ให้ไปแทรกที่ PF_EXT_SLIB และต้อง คัดลอกตัวที่เป็น เฮดเดอร์ไฟล์ไปไว้ใน /iptables-1.2.8/include/linux/netfilter_ipv4/ จากนั้นให้คอมไพล์ ซึ่งจะได้ไฟล์ที่เป็นนามสกุลเป็น .so จากนั้นคิดลอกไปไว้ที่ /usr/local/lib/iptables และ /lib/iptables 

4. พิมพ์คำสั่ง make ภายในไดเรกทอรี่นี้ จะได้โมดูลอันนึงขึ้นมาคือ ipt_WEBDROP.o จากนั้นใช้คำสั่ง insmod ipt_WEBDROP.o 

จากนั้นเป็นอันเสร็จสมบูรณ์ในการเรียกใช้โมดูลนี้
