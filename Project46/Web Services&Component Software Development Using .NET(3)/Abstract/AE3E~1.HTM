บทคัดย่อ

               

                โครงงานนี้เป็นการพัฒนาสถาปัตยกรรม .NET และ J2EE ให้มีความเชื่อถือ และสามารถรองรับการขยายตัวของงานได้มากขึ้น โดยอาศัยหลักการของเทคโนโลยีโหลดบาลานซิ่ง (Load Balancing) เข้ามาช่วยในการแบ่งงานของเซิร์ฟเวอร์และการรองรับความผิดพลาดที่อาจเกิดขึ้น โดยโครงงานนี้ได้รวบรวมทฤษฎี การติดตั้ง และการตั้งค่าต่างๆของสถาปัตยกรรมทั้งสองไว้โดยละเอียด และมีผลการทดสอบประสิทธิภาพของทั้งสองสถาปัตยกรรมเพื่อใช้ในการเปรียบเทียบประสิทธิภาพ

เนื่องจากปัจจุบันมีการใช้อินเตอร์เน็ทเพิ่มขึ้นอย่างแพร่หลาย เว็บเซิร์ฟเวอร์ที่ให้บริการต้องรับภาระหนักจนเกิดการเสียบ่อย ทำให้เสียผลประโยชน์ในทางธุรกิจมากมาย จึงมีวิธีการโหลดบาลานซิ่ง (Load Balancing) เข้ามาช่วยแบ่งเบาภาระจากเดิมที่เซิร์ฟเวอร์ตัวเดียวต้องรับภาระหนักจนเกินไป ก็ทำการเพิ่มเซิร์ฟเวอร์เข้าไปช่วยแบ่งงานกันทำ และยังสามารถเพิ่มความเชื่อถือของเว็บไซน์ได้โดยสามารถรองรับความผิดพลาดที่เกิดขึ้นได้โดยไม่กระทบการทำงานโดยรวม และยังง่ายต่อการดูแลรักษาเพราะสามารถปิดเซิร์ฟเวอร์เพื่อบำรุงรักษาได้

โหลดบาลานซิ่งจึงเป็นอีกทางเลือกในการเพิ่มประสิทธิภาพการทำงานของเว็บแอพพลิเคชันซึ่งสามารถพัฒนาได้ทั้งบนดอทเน็ทเทคโนโลยีและเจทูอีอีเทคโนโลยีซึ่งมีความยากง่ายและข้อดีข้อเสียที่ต่างกัน
