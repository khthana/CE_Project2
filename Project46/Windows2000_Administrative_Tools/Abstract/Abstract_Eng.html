ABSTRACT

            Computer is getting more important in companies and organizations because of useful, comfortable and faster for users. Windows 2000 Server is an operation system which is popular and used in many organizations. With a number of computers, users and resources have a lot that make administrator confused and difficult to manage them. Some work of administrator makes administrator waste time a lot, such as creation a lot of user accounts and configuration of users.

                For this reason, this project is established for making tools to support administrators on Windows 2000 Server and help work of administrator easier, faster and more convenient. The tool is creation a lot of user accounts using user’s details from database, and the other tool is deletion user account tool because when a user account is deleted, some files that belong to the user will not be deleted. Those files will be garbage and waste disk space. Deletion user account tool will search and delete them.
