บทคัดย่อ

 

               

โครงงานนี้เป็นการพัฒนาระบบการเรียนการสอนผ่านทางอินเตอร์เน็ตโดยใช้ความรู้พื้นฐานจากE-Learning มาประยุกต์และพัฒนาขึ้นด้วยภาษา JSP,HTMLและ Mysql รวมทั้งได้ประยุกต์หลักการเรียนการสอนผ่านทางอินเตอร์เน็ตโดยมีการทำการส่งผ่านแบบปฏิสัมพันธ์กับเวลา (Real Time Broadcasting) เพื่อให้ตอบสนองกับความต้องการของผู้เรียนให้มากยิ่งขึ้นโดยใช้เทคโนโลยีทางอินเตอร์เน็ตโดยอาศัยหลักการทำงานแบบ Client – Server และยังมีการใช้ชุดการเรียนการสอน (CAI) วิชาดิจิตอลพื้นฐานมาเป็นแบบเรียนที่ใช้ในการสอน โดยการประมวลผลของเว็บแอบพลิเคชันจะอยู่ที่ฝั่งของเซิร์ฟเวอร์  แล้วส่งผ่านไปให้กับลูกข่ายที่สมัครสมาชิกไว้โดยสามารถเลือกได้ว่าต้องการใช้ความสามารถของระบบนี้ในแบบการส่งผ่านแบบปฏิสัมพันธ์กับเวลา หรือเฉพาะชุดการเรียนการสอน
