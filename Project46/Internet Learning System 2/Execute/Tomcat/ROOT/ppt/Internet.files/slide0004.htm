Internet คืออะไร?
nระบบเครือข่าย
n    คือการนำเอาคอมพิวเตอร์หลายเครื่องมาเชื่อมโยงเข้าด้วยกัน ทำให้ เครื่องคอมพิวเตอร์แต่ละเครื่องแลกเปลี่ยนข่าวสารข้อมูลซึ่งกันและกันได้
nInternet
n    คือระบบเครือข่ายของเครือข่าย Internet ทำให้ผู้ใช้ที่อยู่บนเครือข่ายหนึ่ง เรียกใช้ข้อมูลที่อยู่บนอีกเครือข่ายหนึ่งได้ หรือแลกเปลี่ยนข่าวสารกับผู้ใช้ ที่อยู่ในเครือข่ายนั้นๆที่อยู่ห่างไกลได้
