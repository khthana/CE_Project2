สรุปและวิจารณ์
•โครงงานนี้จัดทำขึ้นเพื่อสร้างโอกาสในการเรียนการสอนที่กว้างและหลากหลายมากขึ้น โดยกลุ่มเป้าหมายคือ นักศึกษาในภาควิชาวิศวกรรมคอมพิวเตอร์มากกว่าเพราะการทำวิดีโอ สตรีมมิ่ง แล้วบรอดคาส ออกไปใช้ แบนวิด  ค่อนข้างสูง จึงเหมาะกับการใช้งานในภาควิชา,สถาบัน มากกว่า  ส่วนบุคคลภายนอกที่เชื่อมต่อเข้ามา ด้วยไดล์ อัพ โมเดม ซึ่งมีความเร็วค่อนข้างต่ำจะเหมาะกับการศึกษาด้วย Powerpoint มากกว่า •จากการจัดทำโครงงานระบบการเรียนการสอนผ่านอินเตอร์เน็ตนี้ทำให้ผู้จัดทำได้รับความรู้จาการศึกษาการเขียนโปรแกรมและประสบการณ์มากมาย เช่น การเขียนเว็บเพ็จด้วย เฮชทีเอมแอล,โครงสร้างของระบบการเรียนการสอน ผ่านอินเตอร์เน็ต,การเขียนสคริปต์ เจเอสพี,การใช้งานฐานข้อมูล มายเอสคิวแอล,การ ติดตั้งเว็บเซิฟเวอร์,การเขียนเอสคิวแอลสคริปต์เพื่อการทำคิวรีข้อมูล  ฯลฯ
