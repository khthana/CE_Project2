วัตถุประสงค์(ต่อ)
•6 เพื่อสร้างโอกาสให้ผู้เรียนที่เป็นใครก็ได้ มาจากที่ใดก็ได้ และเรียนเวลาใดก็ได้ตามความต้องการของผู้เรียน เพราะหน่วยงานได้เปิดเว็บไซต์ให้บริการตลอด 24 ชั่วโมง •7 ใช้สื่อที่นำเสนอในเว็บ ประกอบด้วยข้อความ ภาพนิ่ง ภาพเคลื่อนไหว และเสียง ตลอดจนวีดีทัศน์ ซึ่งจะช่วยกระตุ้นการเรียนรู้ของผู้เรียนได้เป็นอย่างดี •8 เพื่อสร้างโอกาสให้ผู้เรียนสามารถเลือกเรียนเนื้อหาที่นำเสนอได้ตามความต้องการ
