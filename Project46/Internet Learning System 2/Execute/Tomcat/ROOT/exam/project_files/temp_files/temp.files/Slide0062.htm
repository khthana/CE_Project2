แนวทางการพัฒนาต่อ
•ในระบบการเรียนการสอนผ่านอินเตอร์เน็ตนี้ การทำการบรอดคาสนั้นใช้ Window media Encodergrup เพียงตัวเดียวเท่านั้นยังสามารถพัฒนาต่อให้ใช้ real producer หรือ tools ตัวอื่นๆ ได้อีก
•เพิ่มส่วนการประเมินผลให้กับระบบ ทั้งในรูปของผลตอบกลับ (feedback) และ การสร้างแบบทดสอบ (Exam)
•เพิ่มวิชาที่จะทำการเรียนการสอนให้มากขึ้น
•สร้าง แบบจำลองการปฏิบัติการจริงขึ้น (virtual laboratoty)
•เพิ่มการอินเตอร์แอคระหว่างอาจารย์และนักศึกษาให้มากขึ้น เช่น สร้างการประชุมกลุ่มย่อยขึ้น เช่นกลุ่มโปรเจค เป็นต้น หรือการให้คำปรึกษาออนไลน์
•ปรับปรุงฐานข้อมูล และ CAI ให้ทันกับหลักสูตรที่เปลี่ยนแปลงไป
