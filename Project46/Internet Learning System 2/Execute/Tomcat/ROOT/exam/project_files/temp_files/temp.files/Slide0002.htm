วัตถุประสงค์
•1 เพื่อศึกษาระบบการเรียนการสอนผ่านอินเตอร์เน็ตแล้วสร้างเป็นสื่อให้นักศึกษาสามารถทำการเรียนได้ด้วยตนเอง
•2 เพื่อให้เกิดความรู้ความเข้าใจที่ถูกต้องในระบบการเรียนการสอนผ่านอินเตอร์เน็ต
•3 เพื่อศึกษาเทคโนโลยีต่างๆในการสร้างเว็บเพ็จในการนำไปใช้ในการทำโครงงานและงานอื่นๆได้อย่างเหมาะสม
•4 เพื่อเสริมสร้างความเข้าใจในบทเรียนให้กับนักศึกษา
•5 ใช้สามารถของเอกสารเว็บที่มีจุดเชื่อม ย่อมทำให้เนื้อหามีลักษณะโต้ตอบกับผู้ใช้โดยอัตโนมัติอยู่แล้ว และผู้เรียนยังเพิ่มส่วนติดต่อกับวิทยากรผ่านระบบต่างๆ และสมุดเยี่ยม ทำให้ผู้เรียนกับวิทยากรสามารถติดต่อกันได้อย่างรวดเร็ว
