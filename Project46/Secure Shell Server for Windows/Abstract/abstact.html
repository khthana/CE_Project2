บทคัดย่อ
      ปัจจุบันมีผู้ใช้งานระบบปฏิบัติการวินโดวส์เพิ่มขึ้นเป็นจำนวนมาก โปรแกรมอย่างเทลเน็ต (Telnet) ก็มีปัญหาด้านความปลอดภัย เนื่องจากข้อมูลที่ส่งไปไม่มีการเข้ารหัสลับ จึงทำให้การดูแลรักษา และการใช้งานจากระยะไกลก็จะมีปัญหาด้านความปลอดภัยด้วย รวมทั้งระบบปฏิบัติการวินโดวส์ขาดโปรแกรมที่ทำหน้าที่เป็นเซิร์ฟเวอร์ที่สามารถรับการเชื่อมต่อจากระยะไกลได้อย่างปลอดภัย ดังนั้นปริญญานิพนธ์ฉบับนี้ จึงเสนอโปรแกรมที่สามารถลดปัญหาที่กล่าวมาได้คือโปรแกรมซีเคียวเชลเซิร์ฟเวอร์สำหรับวินโดวส์ ซึ่งมีความเข้ากันได้กับโพรโตคอลซีเคียวเชลเซิร์ฟเวอร์เวอร์ชันที่ 2 สนับสนุนการทำอินเทอร์แอกทีฟเซสชัน และการพิสูจน์ตนโดยใช้บัญชีผู้ใช้เดียวกับระบบปฏิบัติการ

Secure Shell Server for Windows

  Thanatip Yindee
  Bhiti Jirojanakul
  Thana Hongsuwan Advisor
  Akkradach Watcharapupong Advisor

ABSTRACT
      Nowadays, there is an increasing number of Windows users. Because of the unencrypted transmission in Telnet-like programs, some security problems occurred in maintenance and remote-access. Due to the lack of secure remote-access server program on Windows platform, this thesis offer Secure Shell Server for Windows as a solution. This program is compatible with Secure Shell Protocol version 2, provides interactive session and supports authentication via Windows account system
