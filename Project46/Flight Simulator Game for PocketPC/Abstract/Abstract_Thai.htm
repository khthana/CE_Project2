บทคัดย่อ

        ปริญญานิพนธ์นี้ นำเสนอการพัฒนาเกมส์จำลองการบินของเครื่องบินที่เป็นภาพเคลื่อนไหว 3 มิติ โดยพยายามจำลองลักษณะทางกายภาพของเครื่องบิน และสิ่งแวดล้อม โดยคำนึงถึงคุณสมบัติบางส่วนทางพลศาสตร์ ของวัตถุในเกมส์ เช่น น้ำหนักของเครื่องบิน แรงโน้มถ่วง ความเร็วของขีปนาวุธ แรงพยุงลม ฯลฯ ซึ่งทำให้การจำลองมีความสมจริง
        การแสดงผล 3 มิติของเกมส์อาศัย Diesel Engine ซึ่งเป็น API สำหรับพัฒนาภาพ 3 มิติบนเครื่องพ็อกเก็ตพีซี ส่วนการจำลองการบิน นั้นได้มาจากการดัดแปลงโปรแกรม JSBsim ซึ่งเป็นตัวสร้างสภาวะแวดล้อมทางคณิตศาสตร์ ที่ใช้แพร่หลายในโปรแกรมจำลองการบิน เช่น Flight Gear สำหรับการติดต่อผ่านทางเครือข่ายของเกมส์ อาศัยการเขียนโปรแกรมสื่อสารบน Winsock API
