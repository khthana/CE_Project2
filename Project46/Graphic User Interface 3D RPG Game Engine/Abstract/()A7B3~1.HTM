การพัฒนาเครื่องมือสร้างเกมประเภท RPG 3 มิติ

แบบเป็นหน้าต่างติดต่อกับผู้ใช้

                                                                                               

                                                                                                                                                                                                                           นาย ชาคริต  สวัสดิรักษ์

                                                                                                                                                                                                                           นาย ชยานนท์  รูปประดิษฐ์

                                                                                                                                                                                                                           ดร. วรวัฒน์  ลิ้มโภคา   อาจารย์ที่ปรึกษา

                                                                                                                                                                                                                           ปีการศึกษา  2546

 

บทคัดย่อ

โครงงานนี้เป็นการพัฒนาโปรแกรมสร้างเกมประเภท RPG 3 มิติแบบหน้าต่างติดต่อผู้ใช้ เพื่อให้นำไปใช้งานง่ายขึ้น โดยที่ผู้สร้างเกมไม่จำเป็นต้องมีความรู้ในด้านการเขียนโปรแกรมเลย ระหว่างการสร้างเกมผู้สร้างสามารถเห็นกราฟฟิกจริงๆที่จะถูกแสดงเมื่อเกมถูกนำไปเล่น สามารถสร้างเนื้อเรื่องผ่านทางการกำหนดเหตุการณ์ต่างๆให้กับเกมได้ และส่วนติดต่อผู้ใช้ของโปรแกรมนี้ถูกออกแบบให้ง่ายต่อการเรียนรู้ เป็นแอพพลิเคชั่นซึ่งผู้ใช้สามารถกำหนดสิ่งต่างๆลงไปในเกมได้ตั้งแต่การเลือกโมเดลไปจนถึงการสร้างเนื้อเรื่องให้กับเกม     ซึ่งผลลัพธ์สุดท้ายก็คือเกมที่สามารถเล่นได้จริงที่มีเรื่องราวเหมือนกับที่ผู้สร้างได้วางไว้ตั้งแต่แรก

                เนื้อหาของปริญญานิพนธ์ฉบับนี้ ในส่วนของ บทที่ 2 ทฤษฏีและหลักการของเกมสามมิติ และ บทที่ 3 ไดเร็คเอ็ก จะมีเนื้อหาตรงกันกับปริญญานิพนธ์ของโครงงาน การพัฒนาเกมสามมิติบนระบบเครือข่าย เนื่องจากเป็นโครงงานในประเภทเกมที่อ้างอิงทฤษฎีเดียวกัน
