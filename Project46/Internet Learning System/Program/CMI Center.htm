 1. อะไรคือ AppServ อยากรู้จัง ? by apples

1. ทำความเข้าใจกับ AppServ
        สำหรับ AppServ นั้นก็คือโปรแกรมที่รวบรวม Packages ต่างๆ ไว้
       โดย Packages หลักๆ เหล่านั้นก็คือ
               - Apache Web Server คือ โปรแกรมที่ทำหน้าที่เป็น Web Server
               - MySQL Database คือ โปรแกรมที่ทำหน้าที่เป็น Database Server
               - PHP Script Language คือ ภาษา PHP ที่เอาไว้เขียนโปรแกรมเกี่ยวกับเว็บ
               - phpMyAdmin คือ ตัวควบคุม MySQL Database ผ่านเว็บไซต์

        ซึ่งโดยทั่วไปแล้วเวลาเราจะติดตั้ง Apache Web Server ลงในเครื่องคอมพิวเตอร์ของเรานั้น ก็ต้องไปดาวน์โหลด Apache มาแล้วทำการติดตั้ง และถ้าเราอยากให้ Web Server สามารถใช้งาน PHP ได้ เราก็ต้องไปดาวน์โหลด PHP มาติดตั้งอีก แล้วก็ทำการ config Apache ให้โหลด Module PHP ต้องไปแก้โน่นแก้นี่ ก็ยุ่งยากพอสมควรทีเดียว ถ้าเกิดเราอยากจะเขียนโปรแกรมติดต่อกับ Database อีก เราก็ต้องไปดาวน์โหลด MySQL Database มาลงอีก แค่นี้ก็เป็นเรื่องวุ่นวายพอแล้ว แถมบ้างครั้งติดตั้งแล้ว รัน PHP ไม่ได้บ้าง MySQL ไม่ยอมทำงานบ้าง โอยมันน่าปวดหัวจริงๆ กับปัญหาการติดตั้งก็ใช้เวลาร่วมหลายนาที-ชั่วโมง ก็อาจเป็นได้ อย่างน้อยเวลาในการติดตั้งที่เสียไปนั้น บวกกับอารมณ์ขุ่นเคืองที่ปล้ำกับมันตั้งนาน มันก็อาจทำเอาเราไม่มีอารมณ์เขียนโปรแกรมวันนั้นเลยก็ได้ และข้อสำคัญของชาวคอมพิวเตอร์ ที่อาจจะเป็นกันซะทุกคนเลยก็ว่าได้ เวลาที่ใช้ Windows นานๆไป ชักเกิดหมั่นใส้มันขึ้นมา ก็ทำการ Formatครับเลย บางคนอาทิตย์ละครั้ง เดือนละครั้ง 3 เดือนครั้งก็มี (ส่วนตัวผมเดือนละครั้ง) แล้วเราจะเอาเวลาไหนมานั่งลง Apache, PHP, MySQL ตลอดหละ สำหรับมือใหม่ที่อยากลองลงด้วยตนเอง ก็ลองเถอะครับมันคือความรู้ของเรา ที่จะลองในสิ่งที่ไม่เคยลองมาก่อน แต่ส่วนใหญ่ที่ลงเป็นแล้ว ก็จะเกิดอาการเบื่อโดยอัตโนมัติเอง เชื่อผมเถอะผมก็เป็นหนึ่งในนั้น 55555 5 5

          เมื่อความขี้เกียจมาเยี่ยมเยียน โปรแกรม AppServ ก็จึงเกิด โดยเราสามารถที่จะติดตั้ง Apache, PHP, MySQL ภายในหนึ่งคลิกทุกอย่างก็พร้อมใช้งานโดยทันที เวอร์ชั่นที่ถอด PHP-Nuke ออกไปรู้สึกว่าจะใช้เวลาแค่ 20 วินาที ก็ติดตั้งเสร็จหมดเลยทุกอย่าง เพียงเท่านี้เราก็พร้อมที่จะเขียน PHP ทำงานกับ Database ภายในเครื่องของเราได้ทันที โดยเครื่องคอมพิวเเตอร์ก็เราก็เปรียบเสมือน Web Server จำลองดีๆ นี่เอง เร่งรีบเมื่อไหร่เรียกหา AppServ ได้ทันที คงเข้าใจกันแล้วนะครับว่า AppServ คืออะไรขั้นตอนต่อไปก็มาดูการติดตั้งกันเลยดีกว่า

2. เริ่มต้นติดตั้ง AppServ กันดีกว่า
          ขั้นตอนแรกเราก็ดาวน์โหลดโปรแกรม AppServ เวอร์ชั่นล่าสุดได้จากเว็บไซต์ http://appserv.sourceforge.net/ ลองหาดูลิ้งค์หน้าแรกนะครับ จะมีบอกไว้ว่าดาวน์โหลดที่ไหน โดยชื่อไฟล์ของโปรแกรม AppServ จะมีตัวอย่างดังต่อไปนี้ appserv-win32-x.y.z.exe
               + win32 อันนี้สำคัญครับ win32 ก็คือติดตั้งได้เฉพาะ Windows ที่เป็น 32 bit ขึ้นไป
                            โดย Windows ที่เป็น 32 bit ก็ตั้งแต่ 98 ขึ้นไป ต่ำกว่านั้นลงไม่ได้ครับ
               + x และ y ก็คือเวอร์ชั่นที่มีการเปลี่ยนแปลงหลักๆ และมีอะไรใหม่ๆ
               + z ก็คือเวอร์ชั่นที่มีการเปลี่ยนแปลงเล็กน้อย เช่น แก้ bug บางอย่าง
          เมื่อดาวน์โหลดเสร็จเรียบร้อยแล้วก็ทำการ Double Click ที่ชื่อไฟล์ได้เลยครับ หลังจากทำการ Double Click แล้วก็จะปรากฏหน้าจอ Setup AppServ ดังต่อไปนี้

                       

                 - รูป ( 1 )  จะบอกให้เราเลือก Path ที่จะทำการติดตั้ง AppServ ลงไป โดย Default Install Path ของ AppServ นั้นก็คือ C:\AppServ หากเราต้องการย้ายไปลงที่อื่นก็แก้ไขได้เลย
                 - รูป ( 2 ) ก็คือการเลือกรูปแบบที่จะติดตั้งก็จะมี Typical ก็คือติดตั้งโปรแกรมที่จำเป็นไปเลย สำหรับ Compact ก็คือการติดตั้งให้เล็กที่สุด ประมาณว่ามีแต่ Apache กับ PHP ถ้าเลือก Custom ก็จะปรากฏรูปที่ 3
                 - รูป ( 3 ) จะมีให้เลือกว่าเราต้องการติดตั้งอะไรบ้าง ก็เช็คเลือกได้เลยตามความต้องการ
                

                       
          
                รูป ( 1 ) Apache Config
                       + Server Name อันนี้ใส่อะไรไปก็ได้ครับ แต่ถ้าไม่อยากให้มีปัญหามาก ขอแนะนำให้ใส่ localhost ครับ
                       + Admin Email ใส่อะไรไปก็ได้ครับช่องนี้ แล้วแต่เรา
                       + HTTP Port อันนี้สำคัญหน่อย ตรงนี้ก็คือ Port ที่จะรัน Apache Web Server โดยมาตรฐาน HTTP Protocol นั้น Port มาตรฐานก็คือ 80 แต่ถ้าหาว่าในเครื่องเรามี IIS อยู่ด้วย ก็สามารถเปลี่ยน Port เป็นหมายเลขอื่นได้ครับ แต่เวลาจะเข้าใช้งานนั้นเราต้องระบุ Port ไปด้วยครับ เช่น http://localhost:81 แบบนี้ครับหากเรากำหนดเป็น Port 81จะแก้หลังจากการติดตั้งก็ได้ครับโดยไปแก้ไขที่ไฟล์ httpd.conf ครับ
                 รูป ( 2 ) MySQL Config
                       + User Name ช่องนี้ก็ใส่ชื่อ userครับไรก็ได้ที่เราต้องการ
                       + Password ช่องนี้ก็ใส่ passwordครับไรก็ได้ที่เราต้องการ
                  *** หมายเหตุ : ในส่วนนี้จะเป็น User & Password ของ ODBC เอาไว้ Start MySQL เฉยๆ จะไม่ใช่ User ที่อยู่ใน Databaseครับครับ อย่างที่มีหลายคนเคยบอกผมว่า AppServ ที่ใช้ MySQL 4.0.xx ไม่ยอม Save Password จริงๆ แล้วไม่ใช่ครับ เหตุผลก็คือ MySQL 3.23.xx นั้นมักง่ายไปหน่อย โดยสามารถเอา User ODBC ระบุอยู่ใน my.ini มาใช้งานได้เลยซึ่งใน my.ini นั้นไม่ได้เข้ารหัสอะไรเลยถือว่าอันตรายมาก ตัว MySQL 4.0.xx จึงทำการแก้ไขตรงจุดนี้โดย User ODBC จะเอาไว้ Start MySQL เท่านั้น หากเราต้องการสร้าง User ก็ต้องทำการ Grant user เอง ในส่วนของ Grant ผมก็จะอธิบายไว้ใน FAQ ที่เกี่ยวกับการสร้าง User สำหรับใช้ Database ลองเข้าไปอ่านดูได้ครับ

               เมื่อเราผ่านขั้นตอนเหล่านี้แล้วโปรแกรมก็จะทำการติดตั้ง AppServ ลงบนเครื่องคอมพิวเตอร์ของท่าน และเมื่อสิ้นสุดการติดตั้ง ก็จะปรากฏหน้าจอดังต่อไปนี้

                       

                จากนั้นกดปุ่ม Close โปรแกรมก็จะทำการ Start Apache และ MySQL เพื่อที่จะใช้งาน จากนั้นเราก็เปิด Web Browser ของเราขึ้นมา ไม่ว่าจะเป็น Internet Explorer, Netscape, Mozilla & etc ก็พิมพ์ใช่ช่อง URL ว่า http://localhost เพียงเท่านี้เครื่องคอมพิวเตอร์ของท่านก็กลายเป็น Web Server/Database Server ดีๆ นี่เอง สำหรับไฟล์ต่างๆ ที่จะเขียน html หรือจะเขียน php ให้เก็บไว้ใน directory www ตามที่ท่าน Install เช่น ถ้าระบุ Install Path ไว้ที่ C:\AppServ ท่านก็เก็บไฟล์ต่างๆ ที่เขียนไว้ได้ที่ C:\AppServ\www
