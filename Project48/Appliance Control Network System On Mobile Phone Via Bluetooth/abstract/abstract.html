บทคัดย่อ

 

                ในปัจจุบันโทรศัพท์เคลื่อนที่รุ่นใหม่ที่ออกมา ส่วนมากจะมีบลูทูธให้มาด้วย โครงงานนี้จะทำการศึกษาและพัฒนาระบบสั่งงานอุปกรณ์ไฟฟ้าผ่านระบบการสื่อสารไร้สายบลูทูธ ซึ่งเป็นหนึ่งในมาตรฐานการสื่อสารไร้สายในอุปกรณ์พกพาที่มีความเร็วสูงมากชนิดหนึ่ง โดยใช้โทรศัพท์เคลื่อนที่ที่มีระบบปฏิบัติการที่มีชื่อว่า  ซิมเบี้ยน ทำให้สามารถเขียนโปรแกรมลงไปในโทรศัพท์โทรศัพท์เคลื่อนที่ได้ โดยในโครงงานนี้ได้เขียนโปรแกรมเพื่อที่จะสามารถสั่งงานอุปกรณ์ไฟฟ้า  เพื่อความสะดวกสบายของผู้ใช้งาน ในการควบคุมเครื่องใช้ไฟฟ้าภายในที่อยู่อาศัย   ผ่านบลูทูธที่เป็นอุปกรณ์พื้นฐานของโทรศัพท์โทรศัพท์เคลื่อนที่ดังกล่าว และยังสามารถติดต่อสื่อสารส่งคำสั่งผ่านข้ามเครือข่ายพิโคเน็ตได้เป็นแบบเครือข่ายสแคตเทอเน็ต ในส่วนที่ติดต่อกับตัวแผงวงจรจะส่งสัญญาณความถี่ต่างๆ ให้กับไมโครคอนโทรลเลอร์เพื่อนำไปประมวลผล และควบคุมอุปกรณ์ไฟฟ้าทั้งการ เปิด ปิด ตามแต่ละอุปกรณ์ได้

ON MOBILE PHONE VIA BLUETOOTH

ABSTRACT

 

                Nowadays most new release mobile phones include Bluetooth. This thesis studies and develops appliance control network system on mobile phone via Bluetooth. Using the operating system called symbian results in being able to write programs in cellophane. This thesis is objected to control appliance for user convenience when using it in their accommodation via Bluetooth which is base equipment of mobile phone. Moreover the system can transfer commands over Piconet (Scatternet). The part attached to circuit broad sends different frequency to Microcontroller for processing and controlling each appliance to open or close it.
