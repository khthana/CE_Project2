
    1. ให้ทำการติดตั้งโปรแกรม appserv-win32-2.5.1 โดยมีขั้นตอนการติดตั้งดังที่ได้อธิบายไว้แล้วใน Thesis (ภาคผนวก ก) หรือในไฟล์ user.doc (ในโฟล์เดอร์ manual)
    2. หลังจากนั้นให้ทำการสร้างโฟล์เดอร์ใน C:\AppServ\www  (สมมติตั้งชื่อโฟล์เดอร์ wbls)
    3. ทำการ Copy ไฟล์และโฟล์เดอร์ทั้งหมด (ยกเว้นโฟล์เดอร์ express) ที่อยู่ในโฟล์เดอร์ source ไปวางไว้ใน C:\AppServ\www\wbls
    4. ทำการ Copy โฟล์เดอร์ express ที่อยู่ในโฟล์เดอร์ source ไปวางไว้ใน C:\AppServ\mysql\data
    5. เปิดโปรแกรม Internet Explorer  แล้วใส่ URL ในช่อง Address คือ http://localhost/wbls/index.php โปรแกรม Web Based Logistic System ก็จะเปิดขึ้นมา และสามารถใช้งานได้
