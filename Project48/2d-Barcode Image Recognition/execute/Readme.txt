การรันโปรแกรมสร้างภาพรหัสแท่งสองมิติ ชนิด ดาต้าเมทริกซ์
---------------------------------------------------------------------------
1. ให้นำโฟล์เดอร์ที่ชื่อ Snapper ซึ่งเป็นโฟล์เดอร์ที่เก็บโปรแกรมแอพพลิเคชั่นบนตัวมือถือ
    โดยจะต้องนำไปเก็บไว้ที่C:\WTK22\apps\  
2. จากนั้นทำการรันโดยใช้โปรแกรม Nokia Developer's Suit 3.0 
3. ทำการเลือกที่เมนู Start Emulator
4. ทำการเลือกที่อยู่ของแอพพลิเคชั่นบนตัวมือถือที่เขียนไว้ชื่อSnapper.jad ซึ่งเก็บไว้ที่ C:\WTK22\apps\Snapper\bin
5. ทำการเลือกรุ่นของ Emulator ที่ต้องการใช้ทดสอบการ Run แอพพริเคชั่นเป็น prototype_2_0_S60_MIDP_Emulator
6. ทำการเลือกที่เมนู Emulate เพื่อ Run แอพพริเคชั่น
