การจัดกลุ่มฟีเจอร์บนนิวรอลเน็ทเวิร์ค

Feature Clustering on Neural Network

 

บทคัดย่อ

 

                วิทยานิพนธ์ฉบับนี้เป็นส่วนหนึ่งของการจัดกลุ่มฟีเจอร์บนนิวรอลเน็ทเวิร์ค โดยใช้ระบบเครือข่ายประสาทเทียมแบบแพร่กลับ (Back-propagation Neural Network: BPNN) โดยจากแนวความคิดที่ว่า ในนิวรอลเน็ทเวิร์คจะมีฟีเจอร์ประกอบกันหลายฟีเจอร์ และฟีเจอร์เหล่านี้อาจจะมีความเกี่ยวข้องกันหรือไม่ก็ได้ ในการพัฒนาจึงมีการจัดกลุ่มของฟีเจอร์ที่เกี่ยวข้องกันไว้ด้วยกัน โดยให้ฟีเจอร์ต่างๆ เป็น อินพุท ของนิวรอลเน็ทเวิร์ค แล้วทำการจัดกลุ่มโดยอาศัยค่าน้ำหนักของระบบนิวรอลเน็ทเวิร์คที่ผ่านการสอนแล้วเป็นค่าอ้างอิงในการจับกลุ่ม โดยระบบเครือข่ายประสาทเทียม ที่ทำการจับกลุ่มฟีเจอร์แล้วนี้จะขอเรียกว่า คลัสเตอร์นิวรอลเน็ทเวิร์ค (Cluster Neural Network) แล้วนำมาเปรียบเทียบกับนิวรอลเน็ทเวิร์คแบบแพร่กลับ (Back-propagation Neural Network) ซึ่งถือว่าเป็นแบบมาตรฐาน เพื่อเปรียบเทียบประสิทธิภาพในด้านต่างๆ

 

ABSTRACT

 

                This thesis is a part of Feature Clustering on Neural Network. The application use back-propagation neural network. From the concept that back-propagation neural network has many features and these may correlate together, or not. Then in the development we will cluster some features together and use them as input of network and train network. After that we use trained network’s weights to cluster features. We will called it as “Cluster Neural Network”, Finally we compare performance of “Cluster Neural Network” with “Back-propagation Neural Network”.
