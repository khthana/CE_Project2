การแทรก Link :
ทำได้โดย ใส่ URL ลงไป แต่ต้องขึ้นต้นด้วย http:// จะทำ link ให้โดยอัตโนมัติ
ตัวอย่าง : http://www.ce.kmitl.ac.th
ผลที่ได้ : http://www.ce.kmitl.ac.th

การแทรก E-mail :
ทำได้โดยใส่ E-mail ตามปกติ จะทำ link ให้โดยอัตโนมัติ
ตัวอย่าง : test@kmitl.ac.th
ผลที่ได้ : test@kmitl.ac.th

ตัวอย่าง : [b]ตัวหนา[/b]
ผลที่ได้ : ตัวหนา

ผลที่ได้ : ตัวขีดเส้นใต้
