บทคัดย่อ

    วิทยานิพนธ์ฉบับนี้เสนอวิธีในการพัฒนาซอฟต์แวร์ ซึ่งเป็นขั้นตอนหนึ่งที่สำคัญเพื่อให้ซอฟต์แวร์ที่พัฒนาขึ้นนั้น มีประสิทธิภาพน่าเชื่อถือ และถูกต้องตามความต้องการของผู้ใช้งานคือขั้นตอนการทดสอบ ในการทดสอบสิ่งที่จำเป็นสำหรับผู้ทดสอบเพื่อใช้ในการทดสอบคือ กรณีทดสอบ ซึ่งการออกแบบกรณีทดสอบนั้นแบ่งออกเป็น 2 ประเภทคือ แบบไวท์บอกซ์ (White-box testing) และแบบแบล็กบอกซ์ (Black-box testing) การออกแบบกรณีทดสอบแบบแบล็กบอกซ์ (Black-box testing) นั้นนิยมใช้ในทุกระดับของการทดสอบ ซึ่งการสร้างกรณีทดสอบแบบแบล็กบอกซ์ (Black-box testing) ผู้ทดสอบต้องทำขั้นตอน ของการแยกชั้นสมมูล (Equivalence class partitioning) เพื่อแยกชั้นสมมูลของข้อมูลเข้าให้เป็นชั้นที่ใช้ได้ และชั้นที่ใช้ไม่ได้ และวิเคราะห์ค่าขอบเขต (Boundary value analysis) เพื่อหาค่าขอบเขตของข้อมูลเข้านั้น ซึ่งทั้งสองขั้นตอนนี้เป็นเรื่องที่ยุ่งยาก และใช้เวลามากสำหรับผู้ทดสอบ ดังนั้นงานวิจัยนี้จึงได้พัฒนาเครื่องมือระบบจัดการกรณีทดสอบซอฟต์แวร์ เพื่อนำมาช่วยผู้ทดสอบในการสร้างกรณีทดสอบ และนอกจากนั้นยังช่วยในการเก็บข้อมูลกรณีทดสอบ การตรวจสอบ การติดตาม การแก้ไข เพิ่ม-ลด กรณีทดสอบที่ผู้ทดสอบใช้ในการทดสอบทั้งหมด เพื่อให้การทดสอบทำได้สะดวกยิ่งขึ้น และเป็นการลดภาระของผู้ทดสอบอีกด้วย โดยการเก็บข้อมูลกรณีทดสอบ และผลการทดสอบภายในระบบ

ABSTRACT

    This thesis is explain about a software testing, an important solution to improve program's performance. In this thesis, we use two solutions for testing program, Black-box and White-box testing. Black-box testing is test program by analyze a value of input and output. In this solution, program tester should generate all test value to program for black-box test, in another way white-box test can analyze program's code for program's path and variable. We can combine black-box with white-box test to assist tester to generate test case boundary and test value moreover this solution can show all program path that tester can use as information for program analysis.
