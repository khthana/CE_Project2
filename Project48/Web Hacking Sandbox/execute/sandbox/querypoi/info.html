Query Poisoning
        เป็นส่วนหนึ่งของ SQL Injection เป็นวิธีการที่ hacker ใช้ Statement SQL ฉีดเข้า
ไปใน Query String บน URL ซึ่ง Query Poisoning เป็นการใช้ Statement SQL ที่
เป็นจริงใส่เพิ่มเข้าไปใน Query String ซึ่งอาจจะเป็น Statementที่ไม่ประสงค์ดีเช่น อาจจะ
Query ดูข้อมูลในส่วนที่ต้องห้ามหรืออันตรายไปกว่านั้นอาจจะทำการลบตารางฐานข้อมูลหรือ
เพิ่มข้อมูลลงฐานข้อมูลได้
        ซึ่งการจะทำอย่างนี้ได้ hacker ต้องมีข้อมูลเกี่ยวกับเว็บเป้าหมายอยู่พอสมควร อย่างเช่น
ชื่อ ตารางฐานข้อมูล filed ฐานข้อมูลซึ่งไม่จำเป็นต้องรู้ทุก filed ก็ได้แต่ที่สำคัญต้องรู้ชื่อของ
ตารางฐานข้อมูล หรือ หากไม่รู้ก็อาจจะคาดเดาจากความน่าจะเป็นของฐานข้อมูลที่ใช้ในเว็บเป้า
หมาย เช่น ถ้าเว็บเป้าหมายเป็นเว็บขายสินค้าชื่อตารางก็อาจเป็น Orders ,Product, price
หรือ หากเป็นตารางของเว็บที่มีระบบสมาชิกอาจจะคาดเดาได้ว่าชื่อตารางหรือชื่อ field อาจจะ
เป็น member, user, username เป็นต้น
        ยกตัวอย่างเช่น

http://เว็บไซต์ขายสินค้าแห่งหนึ่ง/showproduct.asp?ID=3+OR+1=1

        เป็นการแสดงรายการสินค้าทั้งหมดแทนที่จะเป็นไปตามค่า ID ที่ส่งมา ที่เป็นเช่นนี้ก็เพราะ
Statement ที่เพิ่มเข้าไปคือ OR 1=1 นั้นเป็นจริงอยู่แล้วซึ่งตอนที่ติดต่อฐานข้อมูลจะเป็นดังนี้
“SELECT * FROM product WHERE ID=3 OR 1=1” ก็จะ Query ออกมาทั้งตาราง
ซึ่งเราอาจจะใช้วิธีนี้ในการ Query ขัอมูลเช่น UserName หรือ password ได้
