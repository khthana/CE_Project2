วิธีการป้องกัน
       ทำได้โดยการลดหรือไม่ใช้ input type hidden ในการรับส่งค่าสำคัญๆต่างๆซึ่งในPHPนั้นสามารถใช้ตัวแปล SESSION ซึ่งตัวแปล SESSION นั้นจะเก็บเอาไว้ทางฝั่งของ Server ซึ่งจะปลอดภัยกว่าแต่ก็ใช่ว่าตัวแปล SESSION จะปลอดภัยเสียทีเดียวแต่ก็ปลอดภัยกว่า การส่งตัวแปลแบบ Hidden field หรือถ้าหากจำเป็นต้องใช้ ก็ต้องใช้การ Check ค่า ตัวแปล HTTP_REFERER ซึ่งเป็นตัวแปล Environment Variable ของ HTTP เพื่อดูว่าหน้า page ที่ส่งค่ามานั้นมาจากหน้าเว็บของ Server ของ เว็บของเราหรือเปล่าแต่วิธีนี้ก็ยังไม่ปลอดภัยเพราะว่า Hacker สามารถที่จะเขียนส่วนหัวของ Header ของ HTTP ให้สามารถเปลี่ยนค่า HTTP_REFERER ได้เช่นกัน การที่จะให้ปลอกภัยมากขึ้นคือต้องมีการ Check ค่าที่รับมาว่าค่านั้นถูกต้องก่อนการคำนวณราคาสินค้าและต้องมีการ Check ขนาดของค่าที่รับมาว่ามีขนาดไม่เกินที่กำหนดไว้หรือเปล่าด้วย
