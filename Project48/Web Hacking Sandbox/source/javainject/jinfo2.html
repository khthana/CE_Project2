II. Java Injection Cookie Editing

        Java Injection Form Editing กับ Java Injection Cookie Editing มีรูปแบบการทำนั้นก็คล้ายๆกัน
        โดยใช้คำสั่งพื้นฐาน เช่น javascript:alert( document.cookie );ซึ่งคำสั่งนี้จะเป็นการแสดง cookie ให้ดู
        ส่วนการทำ Injection นั้นก็ไม่ยากโดยการใช้คำสั่งเดิมแต่ทำการเปลี่ยนค่า cookie ตามที่เราต้องการ เช่น

javascript:void(document.cookie="Field = myValue");

Field คือตัวแปลของ cookie ส่วน myValue นั้นคือค่า cookie ที่ต้องการเปลี่ยน
