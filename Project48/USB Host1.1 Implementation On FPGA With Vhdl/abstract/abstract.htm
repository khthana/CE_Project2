 บทคัดย่อ  
ปริญญานิพนธ์ฉบับนี้ เสนอรูปแบบการทำงานของของการสื่อสารข้อมูลด้วยบัสยูเอสบีและนำเสนอการพัฒนาส่วนการทำงานของยูเอสบีโฮสต์โดยการพัฒนานั้นจะยึดถือตามข้อกำหนดของมาตรฐานของการสื่อสารข้อมูลด้วยยูเอสบีเวอร์ชัน 1.1 ในการพัฒนาโฮสต์จะทำการพัฒนาโดยใช้ภาษาวีเอชดีแอล ซึ่งผลลัพธ์ของโครงงานจะได้ไลบรารีของการสื่อสารข้อมูลด้วยยูเอสบี ทำให้สามารถนำไปใช้เป็นส่วนประกอบของการพัฒนาวงจรดิจิตอลด้วยภาษาวีเอชดีแอลที่ต้องการความสามารถในการติดต่อสื่อสารข้อมูลด้วยยูเอสบีโดยเน้นการพัฒนาในส่วนการทำงานของการประมวลข้อมูลเท่านั้น ซึ่งในการสื่อสารข้อมูลด้วยยูเอสบีนั้น ยังมีความจำเป็นที่จะต้องใช้ไดร์เวอร์ในการสั่งการทำงานของอุปกรณ์ด้วย

ในการทดลองการทำงานของไลบรารีดังกล่าว จะใช้การทดลองบนอุปกรณ์เอฟพีจีเอ ซึ่งใช้อุปกรณ์เอฟพีจีเอเบอร์ XC3s200 เป็นอุปกรณ์ในการทดลองการทำงาน
 
 abstract  
This thesis proposes a communication on bus USB (Universal Serial Bus) and
development of USB Host which reference from USB 1.1 Standard. The implementation of
USB 1.1 Host is using VHDL (Very High Speed Integrated Circuit Hardware Description
Language). The product of project is a programmer library of USB communication, so it
can be use as a part of other digital circuit development which want to use USB
communication. The focus of project is only a data processing, but in USB
communication also need a device driver to control the process of the USB Host.

In a testing the processing of USB library, I use a FPGA (Field Programmable Gate
Array) device with part number XC3s200 for testing system.
