บทคัดย่อ

 

                วิทยานิพนธ์ฉบับนี้เสนอ การสร้างเกม 3 มิติ ซึ่งเป็นเกมการจำลองการสร้างความสัมพันธ์ของมนุษย์ ซึ่งมีวิธีการสร้างภาพ 3 มิติ การสร้างภาพเคลื่อนไหว การออกแบบและสร้างความฉลาดให้กับตัวละคร โดยลักษณะเด่นของวิธีการที่นำเสนอในวิทยานิพนธ์นี้คือ การออกแบบและสร้างความฉลาดให้กับตัวละคร ให้มีการตอบสนองได้ใกล้เคียงกับมนุษย์มากที่สุด และทำให้ผู้เล่นไม่สามารถคาดเดาการทำงานของตัวละครได้ รวมไปถึงการสร้างสถานการณ์ที่อาจจะเกิดขึ้นได้ในปัจจุบัน ในวิทยานิพนธ์เล่มนี้จะใช้อัลกอลิธึม A-life, Basic Probability รวมไปถึงการใช้ Fuzzy logic ในการสร้างความฉลาดให้กับตัวละคร ซึ่งจะใช้โครงสร้างของ Model-Based reflex Agent ซึ่งในวิทยานิพนธ์เล่มนี้ได้แสดงผลของการแสดงความฉลาดของตัวละครที่มีการจำลองให้คล้ายกับมนุษย์ และการตอบสนองความต้องการของตัวเอง

 

ABSTRACT

 

            This thesis present creating 3-D game that about simulate human relation. We have create 3-D image, movement image, design and create intelligent of each character. Prominent point of this project is designing and creating intelligent of each character to nearby human and player can not guess action of character. Include to make situation as same as real world. In this project we use algorithm A-life, Basic Probability and Fuzzy logic. We create intelligent of each character by use structure of Model-Based reflex Agent that in this thesis has show action from result of character‘s intelligent that simulate nearby human and to respond the requirement of each character.
