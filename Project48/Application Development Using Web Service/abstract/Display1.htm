 บทคัดย่อ  
               วิทยานิพนธ์ฉบับนี้เสนอวิธีการพัฒนาเว็บเซอร์วิสบนจาวาแพลตฟอร์มและนำระบบความปลอดภัยไปใช้ในเว็บเซอร์วิสซึ่งทำให้เว็บเซอร์วิสมีความปลอดภัยและน่าเชื่อถือตามมาตรฐานของ WS-Security และ WS-Interoperability ซึ่งมีความจำเป็นในปัจจุบันซึ่งมีเว็บเซอร์วิสเกิดขึ้นมากมายเพื่อให้บริการแก่ลูกค้าในรูปแบบต่างๆ โดยนำเสนอในส่วนของการ ส่งข้อมูลที่มีความสำคัญระหว่างแพลตฟอร์มเดียวกัน คือ Java กับ Java และ โดยใช้ IBM Websphere Application Developer 5.1.1 และ ต่างแพลตฟอร์มคือ ระหว่าง Java และ  Microsoft  Visual Studio .Net 2003 with WSE 1.0 พร้อมทั้งวิธีการติดตั้ง รวมถึงอธิบายองค์ประกอบอื่นๆของเว็บเซอร์วิส และทดสอบโดยการนำไปใช้ในระบบตัวอย่างของ OLALA EDUCATION ซึ่งพัฒนาให้ระบบใช้เว็บเซอร์วิสและนำหลักการของ WS-Security และ  WS-Interoperability ไปใช้จริง
 
 abstract  

This thesis methods of building Java Web Services which implement Web Service Security and Web Service Interoperability .This thesis also mention about how to implement Security in Java Web Service and how can Java Web Service implement WS-Security using IBM Websphere Application Developer 5.1.1 interoperate with Microsoft .Net with WSE1.0 . And also test in sample Application “OLALA EDUCATION” ,which implement WS-Security in Java and WSE1.0 in Microsoft .Net
