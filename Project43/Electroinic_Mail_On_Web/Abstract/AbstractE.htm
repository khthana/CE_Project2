ABSTRACT

Web based Electronic mail is designed for users to conveniently access to their e-mail in the Computer Engineering department, KMITL. Normally, users are familiar with the PINE program that has a bad interface for new users. Java Server Page and Servlets Technologies are developped from Java Technology. They are included in J2EE, which is an enterprise technology. So Java Language is independent from any platform and has Object-Oriented Programming Design which is easy to implement. In addition, Java has a wide variety of library which can accelerate the coding process.
