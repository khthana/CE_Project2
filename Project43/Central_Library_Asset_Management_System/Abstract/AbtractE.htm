ABSTRACT

From studying the sequence of Central library Asset Management System, developer will experience the problems during the operations. Because the system has too many documents so data can lost easily and slow down operation and error in operating such as inventory drawing, storing the details of repaired durable equipment include report making, so it is very difficult to manage them.

Because of above problems, developer decide to use computer for improve performance in operation by using Microsoft SQL Server 7.0 as DBMS and Delphi 5.0 to develop program. This program can help the officer to manage asset of central library easily.

From testing the new developed system. It can response desire of user to retrieve data, immediately correct and report making that can lead user to the new level of convenient way to manage asset of the Central Library.
