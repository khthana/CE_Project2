ABSTRACT

Web site making for providing information service that an information have to be updated up to date such as news , fashion articles is difficult because provider have to know about HTML and other development tools . Provider will lose time for updating information. Moreover the search is full text search.

The objective of this project is constructed for making a convenient way to manage documents. Consist of Automatic Create Document System that help a provider to create documents easier. A document is in standard form every page. Automatic link to related articles that help reader to read other article that relate in their interesting article. And Search that help user to fine old article . User can specify data for searching. So result of search are articles that user really want.
