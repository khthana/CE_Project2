การป้อนข้อมูลค้นหาบทความ ในการป้อนค่าลงในฟอร์มการค้นหา ผู้ใช้สามารถใช้ เครื่องหมาย “+ - & % “ ” ( ) \” ช่วยนั้นการค้นหา ซึ่งมีความหมายต่างๆดังนี้


“+” หมายถึง “หรือ” เช่น “ ชื่อบทความ = php+perl” หมายถึง ต้องการค้นหาบทความที่มีคำว่า php หรือ perl อยู่ในชื่อบทความ เป็นต้น
“-“ หมายถึง “และไม่มี” เช่น “ชื่อบทความ = java-scribe” หมายถึง ต้องการค้นหาบทความที่มีคำว่า java และไม่มีคำว่า scribe อยู่ในชื่อบทความ เป็นต้น
“&” หมายถึง “และ” เช่น “ชื่อบทความ = java&scribe” หมายถึง ต้องการค้นหาบทความที่มีคำว่า java และมีคำว่า scribe อยู่ในชื่อบทความ เป็นต้น
“%” หมายถึง “อะไรก็ได้” เช่น “ชื่อบทความ = java%scribe” หมายถึง ต้องการค้นหาบทความที่มีคำว่า java ตามด้วยอะไรก็ได้แล้วตามด้วยคำว่า scribe อยู่ในชื่อบทความ เป็นต้น
" “ ” " หมายถึง “คำที่มีอยู่ในเครื่องหมายนี้เท่านั้น” เช่น “ชื่อบทความ = “javascribe”” หมายถึง ต้องการค้นหาบทความที่มีชื่อบทความว่า javascribe เท่านั้น เป็นต้น
“( )” หมายถึง “ทำในวงเล็บในก่อน” เช่น “ชื่อบทความ = applet + (java-scribe)” หมายถึง ต้องการค้นหาบทความที่มีคำว่า java และไม่มีคำว่า scribe หรือมีคำว่า applet อยู่ในชื่อบทความ เป็นต้น
“\” หมายถึง “เครื่องหมายยกเว้น” ใช้ยกเว้นเครื่องหมาย + - & % “ “ ( ) \ เช่น “ชื่อบทความ = c++” จะหมายถึง ต้องการค้นหาบทความที่มีคำว่า c หรืออะไรก็ได้ อยู่ในชื่อบทความ, แต่ถ้า “ชื่อบทความ = c\+\+” จะหมายถึง ต้องการค้นหาบทความที่มีคำว่า c++ อยู่ในชื่อบทความ เป็นต้น
เมื่อยืนยันทำการค้นหา ก็จะแสดงข้อมูลเกี่ยวกับบทความที่ตรงตามเงื่อนไขที่กำหนดไว้ พร้อมทั้งแสดงเงื่อนไขของการค้นหานั้นๆ
