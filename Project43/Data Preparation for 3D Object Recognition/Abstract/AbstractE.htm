Data Preparation for 3D Object Recognition

Jittidej Savathanaphaibul
Chayan Tapabut
AdvisorAssoc. Prof. Dr. Chom Kimpan

ABSTRACT

The main purpose of this thesis is learning about data preparing for 3D Object
Recognition by using Triclop camera. With the fundamental of image processing theory
to us the advantage properties of the object such as size, color and shapes the data in 
Neural Network Training Process. Then the Trained Neural Network start being tested. 
The accuracy of the result form the test is about 90 percent.
