Abstract

This thesis presents the cryptography simulation for security system using VHDL (Very High-speed integrated circuit Hardware Description Language). VHDL is a language that used for hardware decription and supports top-down design it does not depend on any technology. So it's suitable for hardware design.

We designed processs of encryption and decryption includes some needed components that be the famous algorithms such as Triple Data Encrption Standard (3DES), Secure Hash Alogirhtm (SHA) and Message Digest Algorithm (MD5), and also Pseudo Random Number Generator (PRNG) for key generation. All of these components are very useful for developers to implement on hardware devices.
