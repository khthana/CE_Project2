ตัวแปลงภาษา HTML เป็น WML

บทคัดย่อ 

	จุดมุ่งหมายหลักของการสร้างตัวแปลงภาษา HTML เป็น WML คือเพื่อให้อุปกรณ์แว็พสามารถเข้าถึงข้อมูลและบริการต่างๆ ที่เป็นบริการของเว็บ เนื่องจากอุปกรณ์แว็พ
รองรับได้เพียงภาษา WML เท่านั้น แต่ข้อมูลต่างๆ บนเครือข่ายเวิลด์ไวด์เว็บส่วนมากเป็นเอกสาร HTML 
	ปริญญานิพนธ์ฉบับนี้เป็นการสร้างตัวแปลงภาษาอัตโนมัติจาก HTML เป็น WML โดยใช้ความรู้เกี่ยวกับโพรโตคอล HTTP, โครงสร้างภาษาของ HTML WML และ 
XML, XSLT สไตล์ชีต และจาวา ในการทำงานของตัวแปลงภาษาสามารถแบ่งออกเป็น 3 ส่วนคือ ส่วนแรกการตัดแบ่งและดัดแปลงเอกสาร HTML ต้นฉบับโดยใช้จาวาแอพพลิเคชัน
เป็นตัวพาร์เซอร์จาก HTML ให้อยู่ในรูปของโครงสร้างต้นไม้ของ XML ส่วนที่สองเป็นการจัดการกับ XML ซึ่งจะมีการนำ XSLT สไตล์ชีตเข้ามาช่วยในการกำหนดรูปแบบ
การแสดงผลของ XML ส่วนที่สามเป็นการสร้างโค้ดภาษา WML และส่งหน้าผลลัพธ์ไปแสดงผลที่บราวเซอร์ที่เรียกใช้บริการ
	ตัวแปลงภาษาที่ได้พัฒนาขึ้น ได้มีการนำไปประยุกต์ใช้งานจริงและเปรียบเทียบข้อดีข้อเสียกับตัวแปลงอื่นๆ เพื่อเป็นแนวทางในการปรับปรุงต่อไป
