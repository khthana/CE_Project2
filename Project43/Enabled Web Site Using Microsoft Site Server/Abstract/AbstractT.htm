การประยุกต์สร้างธุรกิจบนเว็บไซต์โดยใช้ไมโครซอฟต์ไซต์เซอร์ฟเวอร์

อ.นวพร วรรณวิมลศรี อาจารย์ที่ปรึกษา

ปีการศึกษา 2543

บทคัดย่อ

ในโครงงานนี้เป็นการนำเอาโปรแกรมไมโครซอฟท์ไซต์เวอร์มาประยุกต์ใช้กับการสร้างเว็บไซต์บ้านจัดสรร ซึ่งตัวเว็บไซต์ได้ ถูกจัดทำขึ้นเพื่อแสดงการทำงานด้านเว็บลอจิก ซึ่งเป็นอีกรูปแบบหนึ่งในการทำธุรกรรมอิเล็กทรอนิกส์ โดยได้ทำการจำลองเว็บไซต์ที่สามารถนำเสนอรายละเอียดต่างๆของบ้านจัดสรร โดยได้แบ่งส่วนการทำงานของเว็บไซต์ออกเป็นส่วนของผู้ดูแลระบบหรือผู้ใช้ซึ่งเป็นเจ้าของเว็บไซต์หรือเจ้าของกิจการบ้านจัดสรร โดยเว็บไซต์ในส่วนนี้สามารถที่จะทำการเพิ่ม แก้ไขข้อมูลต่างๆหรือลบข้อมูลที่เกี่ยวกับ โครงการ แบบบ้าน อุปกรณ์ตกแต่ง รวมไปถึงการดูข้อมูลของลูกค้า ข้อมูลการจองของลูกค้า เป็นต้น โดยทำงานผ่านทางเว็บบราวเซอร์ ในส่วนของผู้เข้ามาชมเว็บไซต์หรือลูกค้าสามารถค้นหาบ้านที่ต้องการได้ตามความต้องการ ไม่ว่าจะเป็น งบประมาณทำเลที่ตั้งของโครงการ จำนวนห้องนอน จำนวนห้องน้ำ เนื้อที่ หรือประเภทของบ้าน เมื่อลูกค้าเลือกชมจนได้บ้านที่ถูกใจแล้วยังสามารถทำการเปลี่ยนแปลงอุปกรณ์ตกแต่งได้ และระบบจะทำการคำนวณราคาบ้านให้ใหม่ และยังมีการให้ลูกค้าสามารถจองทำเลของบ้านได้ด้วย และยังมีการแสดงสถิติของแบบบ้าน โครงการที่ได้รับความนิยมจากลูกค้าส่วนใหญ่ที่ทำการจอง

ภายในปริญญานิพนธ์จะประกอบด้วยเนื้อหาโดยคร่าวๆทางด้านทฤษฎีเพื่อให้สามารถทำความเข้าใจกับโครงการและส่วนประกอบของธุรกรรมอิเล็กทรอนิกส์ และมุ่งเน้นไปในส่วนของการแสดงตัวโปรแกรมซึ่งได้ทำการอธิบายแนวคิดและการทำงานไว้โดยละเอียด
