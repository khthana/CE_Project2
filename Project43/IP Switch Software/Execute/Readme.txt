คำอธิบาย
----------------------------------------------------------------------------------------------------------------------------------------------
WinPcap.exe	= ตัว install แพ็กเก็ตไดรเวอร์ 
ซึ่งจำเป็นต้องติดตั้งให้เรียบร้อยก่อนใช้งาน / พัฒนา IP Switch Software (ดูตาม"คู่มื่อโปรแกรม")

IPswitchFW.exe	= ไฟล์สำหรับทดสอบฟังก์ชั่นการ Forward Packet
IPswitch2C.exe	= ไฟล์สำหรับทำ IP Switch กับระบบที่มี NICs จำนวน 2 ใบ
IPswitch3C.exe	= ไฟล์สำหรับทำ IP Switch กับระบบที่มี NICs จำนวน 3 ใบ

IRIS200.exe	= ตัว install โปรแกรมมอนิเตอร์แพ็กเก็ตชนิดหนึ่ง ที่นำมาใช้ทดสอบผลการทำงาน
ของซอฟตแวร์ไอพีสวิตช์ในเครื่องพีซีที่รัน IP Switch Software อยู่ ซึ่งเป็น Trial version
โดยให้ติดตั้งและเรียกใช้บนเครื่อง Host ใดๆ ของเครือข่าย

----------------------------------------------------------------------------------------------------------------------------------------------
Explanation (If your system can not read in "Thai" language.)
----------------------------------------------------------------------------------------------------------------------------------------------
WinPcap.exe	= "Packet Driver" installer file.
It is necessarily for run / debug IP Switch Software (Details are in "User Manual").

IPswitchFW.exe	= Executable Code for testing "Packet Forwarding" module.
IPswitch2C.exe	= Executable Code of IP Switch Software - 2 NICs supported version.
IPswitch3C.exe	= Executable Code of IP Switch Software - 3 NICs supported version.

IRIS200.exe	= One of "Packet Monitoring" that was used to test the result of 
IP Switch Software that operated on the any PC. Remeber that it is a trial version.
This program should be installed and run on any Host Computer on a testing LAN network.
