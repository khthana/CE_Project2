บทคัดย่อ

โครงงานนี้ เป็นการศึกษาเกี่ยวกับเทคโนโลยีแวป และภาษาจาวา เนื่องจากผู้จัดทำได้ตระหนักว่า แวปเป็นเทคโนโลยี ที่เป็นประโยชน์ และคาดว่าจะใช้กันอย่างกว้างขวางในอนาคตอันใกล้นี้ ด้วยคุณสมบัติหลายๆประการ โครงงานนี้ ได้นำเอาความรู้ที่ได้จากการศึกษา มาทำการพัฒนาเป็นโปรแกรมเพื่อนำไปใช้ประโยชน์ต่อไป โครงงานนี้ จะเป็นการพัฒนาโปรแกรม ในลักษณะของเซิร์ฟเวอร์ สำหรับให้บริการเกี่ยวกับการทำรายการสินค้า โดยใช้ Microsoft Access ในการจัดเก็บข้อมูล ซึ่งผู้ใช้บริการสามารถลงทะเบียนผ่านทางแวป และทำการ Update ข้อมูลโดยแวป นอกจากนี้ยังมีบริการส่ง message ระหว่างผู้ใช้และบริการตรวจสอบจดหมาย จาก POP3 Mail Server ผ่านทางโทรศัพท์มือถือ ที่มีความสามารถในการใช้งาน แวป ได้
