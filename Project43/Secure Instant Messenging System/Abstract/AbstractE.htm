ABSTRACT

            Nowadays,the online instant messenger softwares,such as ICQ, are very popular.But it does not appropriate to use in organization who need security. Because message may be entraped during send.  This project offers a secure instant messenger which use ICQ for prototype and increase encrypts/ decrypts portion. This project development by  java language because it can run on many platforms.
