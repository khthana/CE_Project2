การ์ตูนใหม่

เรื่องของเรื่องมันก็เริ่มจาก ..เด็กผู้ชายคนหนึ่งที่แสนจะขี้เกียจ เรียนก็ไม่เก่ง และไม่มีความมั่นใจในตัวเอง จะใครซะอีกล่ะ ก็เด็กชาย โนบิ โนบิตะไงล่ะแต่ละวัน โดนเพื่อนแกล้ง ครูตี แม่ดุ ไม่เว้นวัน ช่างน่าสงสาร แล้วต่อไปจะเป็นผู้ใหญ่ที่ดีได้อย่างไร ดังนั้นสิ่งปาฏิหารย์ ก็เกิดขึ้น มีหุ่นยนต์จากโลกอนาคตรูปร่าง เหมือนแมวตัวอ้วนกลมตัวหนึ่งถูกส่งมาเพื่อคอยช่วยเหลือโนบิตะ
และ เขาก็คือ...โดเรมอน


เป็นเรื่องเกี่ยวกับนักวิทยาศาสตร์ที่ชื่อว่าเซ็นเบ้ โนริมากิ และหุ่นยนต์ชื่อ อาราเล่ โนริมากิ ทั้งคู่อาศัยอยู่ที่หมู่บ้านเพนกวิ้น ..ที่ซึ่งหมูเดินบนสองขาหลัง และพระอาทิตย์กินไอศครีม พร้อมกับบ่นว่าทำไมถึงร้อนเช่นนี้

การ์ตูนน่าอ่าน

ดราก้อนบอล เป็นเรื่องราวของการต่อสู้และผจญภัยของโงะคุ (Gokou) เด็กที่มีหางเป็นลิงและมีพละกำลังมหาศาล
วันหนึ่ง เขาได้พบกับบัลม่าซึ่งกำลังตามหาดราก้อนบอลอยู่ โงะคุตัดสินใจช่วยตามหาดราก้อนบอลที่เหลือได้จนหมด ระหว่างการผจญภัย เขาได้พบทั้งเพื่อนและศัตรูมากมายจนเกิดเป็นเรื่องราวต่างๆ ขึ้น

 

เรื่องราวเริ่มขึ้นเมื่อ "ซากุระอิ" ถูกปฏิเสธจากเด็กผู้หญิงในโรงเรียนถึง 50 คน และผู้หญิงคนที่ 50 ปฏิเสธเขาเพราะเธอไปชอบนักบาสเก็ตบอลของโรงเรียน ทำให้ซากุระอิเสียใจและเกลียดบาสเก็ตบอลมาตั้งแต่นั้น แม้แต่ถ้ามีใครพูดคำว่า "บาสเก็ตบอล" ก็ทำให้เขาทนไม่ได้แล้ว อย่างไรก็ตาม ทุกสิ่งก็ได้เปลี่ยนแปลงไปอย่างรวดเร็ว เมื่อเขาได้เข้าเรียนที่ "โชโฮคุ" และได้พบกับ "ฮารุโกะ" ผู้หญิงในฝันของเขาซึ่งชื่นชอบบาสเก็ตบอลเป็นชีวิตจิตใจ และเพื่อเอาชนะหัวใจเธอ ซากุระอิตัดสินใจเข้าร่วมทีมบาสเก็ตบอลของโชโฮคุ แม้ว่าเขาจะไม่รู้อะไรเลยเกี่ยวกับบาสเก็ดบอลก็ตาม แต่โชคร้ายก็ยังเป็นของเขาไม่เปลี่ยนแปลง เมื่อฮารุโกะกลับไปชอบ "รุคาว่า" นักบาสเก็ดบอลคนหนึ่งในทีมแทน
แต่จากการฝึกฝนอย่างหนัก ก็ทำให้ซากุระอิ สามารถพิสูจน์ความสามารถในกีฬาบาสเก็ดบอล ที่ไม่มีขีดจำกัดของเขา กับดาวเด่นของทีม "รุคาว่า" และคนอื่นๆ
...พวกเขาได้ร่วมกันทำให้ทีมโชโฮคุ กลายมาเป็นทีมที่แข็งแกร่งทีมหนึ่ง...ในกีฬาบาสเก็ตบอล
