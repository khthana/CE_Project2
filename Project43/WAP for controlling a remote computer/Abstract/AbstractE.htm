Abstract
          WAP is a protocol that merges two network technologies, wireless data and Internet. Because wireless device is portable, it is design to be small. Then wireless device has some restriction such less powerful CPUs, less memory, restricted power consumption, and small display, adding with restrict of the wireless network such as less bandwidth and less connection stability, then the protocol must be specified to integrate the wireless network with Internet that has higher bandwidth than wireless network. The purpose for developing WAP is to help users who are using wireless device to connect to the Internet that is growing rapidly now.
          This thesis presents developing WAP for controlling a remote computer. The purpose of this thesis is to facilitate the users who is using wireless device to control remote computer without thinking about distance. Not only WAP is used in this thesis, network programming is also used. It is used to develop in connecting and controlling remote computer. With the reason that Java is the object-oriented language that can easily implement in network programming, Java is chosen to implement this system. And Java RMI is used as a part of system's framework.
          The result of developing the system, user can use system's service to control remote computer for specified function. Knowledge from this thesis can be applied to develop other functions for controlling remote computer.
