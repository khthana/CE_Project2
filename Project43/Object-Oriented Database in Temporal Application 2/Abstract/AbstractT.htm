บทคัดย่อ

ระบบฐานข้อมูลในปัจจุบันได้นำเอาแนวคิดของออบเจ็กต์มาใช้พัฒนาเป็นระบบฐานข้อมูลเชิงวัตถุ เพื่อรองรับข้อมูลที่มีโครงสร้างซับซ้อน ซึ่งฐานข้อมูลเชิงสัมพันธ์ไม่เหมาะกับข้อมูลดังกล่าว อีกทั้งระบบฐานข้อมูลเชิงวัตถุสามารถนำมาประยุกต์ใช้งานกับข้อมูลเชิงเวลา ซึ่งเป็นข้อมูลที่มีการเปลี่ยนแปลงตามเวลาได้เป็นอย่างดี โครงงานนี้ได้ทำการศึกษาแนวความคิดเกี่ยวกับฐานข้อมูลเชิงวัตถุและการประยุกต์การใช้งานเชิงเวลา โดยอาศัยระบบการจัดการฐานข้อมูลชื่อ Caché และได้ประยุกต์ออกแบบฐานข้อมูลบุคลากรซึ่งเป็นฐานข้อมูลเชิงเวลาที่ใช้ในสถาบันอีกด้วย
