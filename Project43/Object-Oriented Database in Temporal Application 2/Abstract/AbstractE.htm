ABSTRACT

Nowadays, the concept of Object has been used to develop Database System to be Object-Oriented Database. In order to support complex data which Relational Database is not suitable. Furthermore, Object-Oriented Database could apply to implement Temporal data, that vary by time. This project researches about Object-Oriented Database in Temporal application by using Object-Oriented Database Management System called Caché and also apply to design and implement Personnel database using in Institute that bases on temporal database.
