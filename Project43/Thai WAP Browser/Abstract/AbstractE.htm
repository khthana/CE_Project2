ABSTRACT

Thai WAP Browser in this project is built to support Thai mobile users. Main functions of this browser are able to access WAP sites, support WAP developers who write WML content and emulate operations of wireless device that based on PC. This browser is able to support Thai language when compares with other WAP browsers.

This browser is analyzed and designed in object-oriented method by using UML approach and implemented by JAVA Programming. The technique in this project is conversion of WML to HTML content and use JAVA component that support HTML for displaying and covering the most tags of WML.
