NAME

wbmpconv - Convert bitmaps to/from wbmp format

SYNOPSIS

wbmpconv [options] infile [outfile]

DESCRIPTION

wbmpconv converts almost any graphic file into WBMP format. It will also convert WBMP files back into other graphic formats, or for that matter it will convert directly between any two supported formats, changing any colour image into monochrome as it does so.

A preview option allows the converted image to be displayed before the output file is saved.

OPTIONS

-c format
Sets the format out the output file. If omitted, the output format is set based on the file extension.
-w width
Resizes the image to exactly width bytes wide. The height is not changed unless -h is also specified.
-h height
Resizes the image to exactly height bytes high. The width is not changed unless -w is also specified.
-W width
Resizes the image to not more than width bytes wide. The aspect ratio of the image is preserved.
-H height
Resizes the image to not more than height bytes high. The aspect ratio of the image is preserved.
-f
Lists all supported image formats. All formats may be used for input, only those marked with a star may be used as output file formats.
-p
Preview the resulting file. If outfile is specified then Save and Cancel buttons are available and the output is only written of Save is pressed.
If -p is specified the outfile argument is optional, otherwise both infile and outfile must be given.

FILES

infile is the input file. It may be in any supported format. outfile is the output filename. It may be in any format supported for output. Output GIF files are not compressed.

LIMITATIONS

None known.
