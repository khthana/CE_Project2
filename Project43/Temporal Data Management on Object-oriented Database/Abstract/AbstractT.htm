บทคัดย่อ

ตามธรรมชาติของข้อมูลนั้นจะมีการเปลี่ยนแปลงไปตามเวลา  แต่ฐานข้อมูลในปัจจุบันสามารถเก็บได้เฉพาะสถานะปัจจุบันของข้อมูลเท่านั้น  ทำให้ไม่สามารถเรียกใช้สถานะในอดีตของข้อมูลได้ซึ่งอาจจะทำให้มีปัญหากับการเรียกค้นในภายหลัง  หากต้องการให้ข้อมูลที่เก็บมีหลายสถานะ ต้องขยายความสามารถของฐานข้อมูลในปัจจุบันให้รองรับกับข้อมูลเชิงเวลาได้  และด้วยคุณสมบัติของฐานข้อมูลเชิงวัตถุ  การจะเพิ่มโครงสร้างข้อมูลและโอเปอร์เรชันที่จัดการกับเวลาทำได้ไม่ยากนัก  โดยจะเก็บช่วงเวลาที่แต่ละสถานะของ   ข้อมูลเป็นจริง  หรือช่วงเวลาที่แต่ละสถานะของข้อมูลถูกเก็บในฐานข้อมูลโดยจะใช้ภาษา OQL (Object Query Language) ของฐานข้อมูลเชิงวัตถุร่วมกับโอเปอร์เรชันที่สร้างไว้  เพื่อจัดการและเรียกค้นข้อมูลเชิงเวลาให้ได้ตามต้องการ
