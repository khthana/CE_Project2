How exactly do I search Virtual Library ?

--Simple answer : type a word (or several words) into the "query box"

onVirtual Library page, and then hit the "Search" button (or the "Enter" key on

your keyboard). Virtual Library Search will then look for any "matches" with your

query in the Virtual Library directory.

TIPS

--Matches on all words (AND)

Matches on all words (AND)

Matches on any words (OR)

 

Example : If you type the phrase Java Jsp into the "query box" and check

the radio button AND . It means that the terms "Java" and "Jsp" will be found

in the documents.
