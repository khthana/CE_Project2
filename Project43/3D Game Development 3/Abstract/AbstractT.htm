การพัฒนาเกม 3 มิติ

นายศรุต พจนปรีชากุล 40010766

นายศักดิ์พจน์ ทองเลี่ยมนาค 40010775

ดร. วรวัฒน์ ลิ้มโภคา อาจารย์ที่ปรึกษา

ปีการศึกษา 2543

บทคัดย่อ

การพัฒนาเกม 3 มิติเป็นโครงงานที่กล่าวถึงการเขียนโปรแกรมเกม 3 มิติ โดยใช้ไดเร็กเอ็กซ์และ มอร์ฟิทเอนจิ้น เป็นเครื่องมือช่วยในการพัฒนาโปรแกรม ไดเร็กเอกซ์เป็นเทคโนโลยีที่ถูกสร้างขี้นมาเพื่อช่วยให้ผู้พัฒนาซอฟต์แวร์ ดึงความสามารถของอุปกรณ์ฮาร์ดแวร์ต่างๆ มาใช้อย่างมีประสิทธิภาพและให้เกิดประโยชน์สูงสุด ส่วน มอร์ฟิทเอนจิ้น เป็น แอพพลิเคชั่นโปรแกรมอินเทอร์เฟส ที่ใช้ในการพัฒนาโปรแกรม 3 มิติ

ขอบเขตของโครงงานนี้โครงงานนี้เป็นการสร้างเกมในรูปแบบ เกมยิงในมุมมองบุคคลที่ 1 บนระบบปฏิบัติการวินโดวส์ โดยจะใช้มอร์ฟิทเอนจิ้น เป็นหลักในการพัฒนากราฟิก 3 มิติ และในส่วนที่เหลือจะใช้ไดเร็กเอกซ์ 8 เป็นเครื่องมือในการช่วยเขียนโปรแกรม เริ่มจากการสร้างโมเดลจำลองฉากภายในเกมด้วยโปรแกรม สามดี สตูดีโอ แม็กซ์ แล้วจึงใช้มอร์ฟิทเอนจิ้นควบคุมวัตถุ 3 มิติต่างๆ ภายในฉาก รวมถึงการควบคุมลำดับเหตุการณ์ที่เกิดขึ้นภายในเกม และการตอบสนองอินพุตจากผู้เล่นโดยใช้ไดเร็กอินพุต
