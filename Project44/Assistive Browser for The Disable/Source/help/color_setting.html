Assistive Browser for The Disable
โปรแกรมควบคุมบราวเซอร์สำหรับช่วยเหลือคนพิการ


ส่วนของการตั้งค่าการเปลี่ยนสีต่างๆ



จะเป็นการตั้งค่าสีต่างๆ บนแป้นพิมพ์เสมือนของโปรแกรม Assistive Browser ซึ่งจะใช้การผสมสี 3 สี ระหว่าง แดง เขียว และน้ำเงิน ซึ่งสามารถปรับแต่งค่าโดยเลื่อนได้จาก Scroll Bar ซึ่งจะทำาร Load และ Save ข้อมูลที่ถูกตั้งไว้ส่วนตัวได้
