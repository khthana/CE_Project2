Assistive Browser for The Disable
โปรแกรมควบคุมบราวเซอร์สำหรับช่วยเหลือคนพิการ


ส่วนของการใช้งานแป้นพิมพ์

 

จะอยู่ตรงกลาง ดังรูป ทำหน้าที่รับการคลิกจากระบบ Auto Click ซึ่งสามารถตั้งเวลาในการคลิกได้ แล้วจะส่งค่านั้น ไปยังวินโดวส์ที่ Active อยู่
วิธีการทำให้วินโดวส์ที่เราต้องการส่งข้อความ Active ก็เพียงแค่คลิกที่วินโดวส์นั้น
สามารถสังเกตุที่ Taskbar สีจะเข้มกว่า การทำงานของปุ่มต่างๆ จะคล้ายกับคีย์บอร์ดทั่วๆ ไป สามารถพิมพ์ได้ทั้งภาษาไทยและภาษาอังกฤษ
และสามารถใช้ฟังก์ชันต่างๆ ได้ รวมถึง Short key ด้วย เช่น Ctrl + C เป็นต้น
