ABSTRACT

                This thesis presents a development of an encoding and decoding speech signal as specified in ITU-T G.729 standard. It is useful for Voice over IP project since its capacity can improve the performance of communication systems like the internet. However, we try to search for algorithm which can decrease the complexity of the system while enhance this standard. We have implemented the proposed technique on DSP chip TMS320C6713
