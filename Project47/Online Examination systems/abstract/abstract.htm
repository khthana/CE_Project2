 บทคัดย่อ  
          โครงงานนี้  เป็นการพัฒนาระบบการจัดการสอบผ่านเครือข่าย   ซึ่งระบบแบ่งการทำงานออกเป็น   5  ส่วน คือ  การสอบ  การออกแบบข้อสอบ  การประเมินผล  การติดต่อสื่อสาร และการบริหารจัดการระบบ  ส่วนผู้ใช้งานระบบ แบ่งออกเป็น  3 กลุ่ม คือ อาจารย์  นักศึกษา และผู้ควบคุมระบบ  โดยอาจารย์สามารถที่จะออกแบบข้อสอบ, กำหนดรูปแบบข้อสอบ, รวมทั้งกำหนดเวลาในการสอบ   นักศึกษาสามารถทำการสอบ และดูผลการสอบหลังสอบเสร็จ  ผู้ดูแลระบบสามารถ เพิ่ม-ลบ จำนวนอาจารย์, นักศึกษา  และกำหนดรหัสผ่านในการเข้าใช้งานของผู้ใช้แต่ละคน
          โครงงานนี้ได้ใช้ระบบปฏิบัติการวินโดวส์ (Windows), ภาษาวิชวลเบสิค (Visual Basic) และไมโครซอฟท์เอสคิวแอลเซิร์ฟเวอร์ (Microsoft SQL Server) ในการพัฒนาระบบ
 
 abstract  
          This Project is the examination management system on network. The
examination system consist of five to divide part are examination, creation,
evaluation, communication and management.  The group of users is divided to three
groups such as student, teacher and administrator. The teacher can create the test
form, type of test form and time limited to examine. Student can use it for the
examination.     Administrator can add, delete and create password for all users 
          This project uses Microsoft Windows operating system, Visual Basic language
and Microsoft SQL Server in the system development
