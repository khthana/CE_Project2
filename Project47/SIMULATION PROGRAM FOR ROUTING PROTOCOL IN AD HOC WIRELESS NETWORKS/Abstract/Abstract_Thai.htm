บทคัดย่อ

ระบบเครือข่ายได้เข้ามามีบทบาทกับชีวิตประจำวันมากขึ้น ความต้องการในการนำคอมพิวเตอร์ไปใช้ในการติดต่อสื่อสารหรือ เชื่อมต่อเพื่อให้บริการแก่กันก็มากขึ้นตามไปด้วย โดยเฉพาะในปัจจุบัน เครือข่ายไร้สายแบบแอดฮอคเป็นทางเลือกหนึ่งในการเชื่อมต่อที่ลงทุนต่ำและเหมาะสำหรับเครือข่ายที่มีอายุการใช้งานในระยะสั้น แต่เครือข่ายไร้สายแบบแอดฮอคก็ยังมีข้อจำกัดอยู่มาก การทำความเข้าใจกับเครือข่ายไร้สายแบบแอดฮอคก่อนที่จะนำไปใช้งานจริงจึงเป็นสิ่งจำเป็น

ดังนั้นการจัดทำโปรแกรมจำลองเหตุการณ์เพื่อศึกษาโพรโตคอลการพิจารณาเส้นทางในเครือข่ายไร้สายแบบแอดฮอค จึงเป็นแนวคิดที่ต้องการเปิดโอกาสให้กับบุคคลทั่วไปที่มีความสนใจทางด้านเครือข่ายไร้สายแบบแอดฮอคแต่ไม่มีเครือข่ายจริงให้ทำการศึกษา ได้ทำความเข้าใจกับการทำงานของโพรโตคอลการพิจารณาเส้นทางในเครือข่ายไร้สายแบบแอดฮอคต่อไป โดยโปรแกรมใช้หลักการของ Object Oriented Programming และพัฒนาโดยภาษาจาวา
