ABSTRACT

 

                        This thesis presents a design and implementation of voice the echo canceller using DSP chip TMS320C6713 as core processor with 32 tabs based on LMS, NLMS and RLS adaptive transversal filter algorithm. The design structure of adaptive filter is parallel arithmetic with       Multi channel depending on the Texas Instruments’s Algorithm Standard.

                        This thesis can be the prototype for implement the echo cancellation in telephone system. We used DSP chip processing of Texas Instruments  that is high performance digital signal processing to implement this project and read an input  from normal text files, then was simulated the output by program MATLAB.

                        Since the project followed by signal processing theory and formed the program to algorithm standard according to Texas Instruments standard, so users or programmers can use this project to develop in the real telephone system later.
