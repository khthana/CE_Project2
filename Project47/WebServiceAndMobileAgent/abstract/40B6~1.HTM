ABSTRACT

 

Nowadays, Most Business Transactions are done on the internet. The System that supports these transactions is complex and integrated with the related system  so the most inportant aspect that develops the system is how to improve and unified the standard about communication between the systems.

 

The webservices is one standard which has been developed for a year by many major players on software development such as Microsoft , IBM , SUN Microsystem. It is a unified standard and donít depend on laguage , platform or operating system that used to develop the system but it relates with the information. The webservices describes about the structure ës information , the service that the application server provides the other application.

 

The purpose of  this thesis is to make the security on the webservices application developed by JAVA. We demonstrate how to provide the security to the webservices application by developing security webservices application,  Olala Movie,  is DVD/CD online system and  use the newly security protocol for webservice, ws-security, to provide security for Olala Movie. The application consists of many called services and uses a mobile agent to compute how to get the cheapest price in many dealers.
