ABSTRACT
An embedded system is a computer system which is world wild used and involved in our daily life. Lot of things from watch, mobile phone, and so on control system in small factory are made from it. Linux System is one choice for developing the embedded system. The Linux has the ability in adjustment with many equipments and well known by many developers. The embedded system, developed with Linux, called Embedded Linux System.
A team studies Linux and Embedded System. The study developed the system to control crane in vertical and horizontal direction. Debian Linux, which is compact and easy adjustment, is selected as main system for testing ability and efficiency of Embedded Linux System. Furthermore the team developed the computer's program in Linux Device Driver Module which can well operate with Linux Kernel.
This project is a sample for developing Linux in Embedded System. This development can be used in larger system. There are many examples. A large inventory is computerized for higher accuracy. An automated trade system can be stored and added sale history from existing system. Therefore the development of the Embedded Linux System is the worth for programmers and other computer and electronic developers.
