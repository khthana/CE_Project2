บทคัดย่อ

ระบบสมองกลฝังตัว (Embedded System) เป็นระบบคอมพิวเตอร์ที่ถูกใช้งานอย่างกว้างขวาง และเข้ามาบทบาทในชีวิตประจำวันของบุคคลทั่วไปมากขึ้น ตั้งแต่นาฬิกาข้อมือ โทรศัพท์มือถือ ไปจนถึง ส่วนควบคุมขนาดเล็กในโรงงานอุตสาหกรรมล้วนแล้วเป็นผลมาจากประดิษฐ์กรรมระบบสมองกลฝังตัวทั้งสิ้น ระบบปฏิบัติการลีนุกซ์เป็นอีกทางเลือกหนึ่งในการพัฒนาระบบสมองกลฝังตัว ด้วยเหตุที่ลินุกซ์มีความสามารถในการปรับเปลี่ยนตัวเองให้เหมาะสมกับอุปกรณ์ได้หลากหลายตระกูล และได้รับความนิยมจากนักพัฒนาในปัจจุบัน ด้วยเหตุนี้จึงเกิดระบบสมองกลฝังตัวที่ใช้ลีนุกซ์เป็นระบบปฏิบัติการเรียกว่า Embedded Linux Systems

ผู้จัดทำได้ทำการศึกษาการทำงานของลีนุกซ์และระบบสมองกลฝังตัว เพื่อนำมาใช้สร้างระบบจำลองการควบคุมเครนที่สามารถเคลื่อนที่ได้ทั้งในแนวตั้งและแนวนอน เพื่อทดสอบความสามารถและ ประสิทธิภาพของระบบสมองกลฝังตัวที่ทำงานบนลีนุกซ์ ซึ่งผู้จัดทำได้นำ Debian Linux มาเป็นระบบปฏิบัติการหลักในการทำงาน ด้วยเหตุที่มีความกระทัดรัดและง่ายต่อการปรับแต่ง นอกจากนี้ผู้จัดทำได้เขียนโปรแกรมในลักษณะ Linux Device Driver Module ซึ่งเป็นโปรแกรมที่สามารถผนวกการทำงานเข้ากับ Linux Kernel ได้เป็นอย่างดี

ปริญญานิพนธ์นี้เป็นเพียงตัวอย่างการใช้งานระบบสมองกลฝังตัวที่ใช้ลีนุกซ์ โดยแนวทางการพัฒนาอาจนำไปพัฒนาใช้งานในระบบที่ใหญ่ขึ้น เช่น ระบบจัดเก็บสินค้าที่มีขนาดใหญ่ที่มีการใช้คอมพิวเตอร์ช่วยในการจัดเก็บเพื่อความแม่นยำ หรือระบบขายของอัตโนมัติที่สามารถเก็บประวัติการซื้อของลูกค้าแต่ละคนเพิ่มเติมจากระบบเดิม เป็นต้น ดังนั้นการพัฒนาระบบสมองกลฝังตัวด้วยลีนุกซ์จึงเป็นการศึกษาที่มีเป็นประโยชน์ต่อโปรแกรมเมอร์ , นักพัฒนาอุปกรณ์คอมพิวเตอร์และอีเล็กทรอนิกส์ ในอนาคต
