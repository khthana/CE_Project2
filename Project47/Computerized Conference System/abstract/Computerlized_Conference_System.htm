 บทคัดย่อ  
          ปัจจุบันการทำงานในทุก ๆ สาขาจะเห็นได้ว่าการทำงานของระบบธุรกิจทุกระบบที่มีประสิทธิภาพ และประสิทธิผลจำเป็นต้องเริ่มจากการประชุมวางระเบียบแบบแผน เพราะการวางแผนที่ดีจะเป็นเสมือนเข็มทิศที่ช่วยนำพาระบบการทำงาน ให้ดำเนินไปอย่างสอดคล้องและเป็นไปในทิศทางเดียวกัน
          โครงงานนี้จึงถูกจัดทำขึ้น เพื่อนำความรู้ด้านการใช้คอมพิวเตอร์มาประยุกต์เพื่อแก้ปัญหาบางประการที่เกี่ยวข้องกับการประชุม อาทิ การจัดเก็บเอกสารอย่างไม่เป็นระบบระเบียบ ภาวะขยะล้นสำนักงาน และยังช่วยอำนวยความสะดวกต่างๆ ให้การประชุมเป็นไปอย่างราบรื่น ช่วยสร้างและเก็บ หลักฐานการประชุมอย่างมีระบบ ช่วยลดปริมาณเอกสารในการประชุม และยังช่วยให้การทำงานมี ประสิทธิภาพมากขึ้นอีกประการหนึ่ง
          ระบบการทำงานดังกล่าวจะใช้เครื่องคอมพิวเตอร์ที่มีจอภาพแบบสัมผัสอย่างน้อย 4 เครื่อง แบ่งตามประเภทของผู้เข้าประชุม คือ ประธานการประชุม เลขานุการ กรรมการ และเครื่องที่แสดงผลออกทางเครื่องฉายภาพ (Projector) และจะทำการเก็บเอกสารที่ต้องใช้ในการประชุมทั้งหมด ให้อยู่ในรูปแบบของ PDF file และตัวระบบจะทำการเก็บไฟล์ข้อมูลการประชุมไว้ในฐานข้อมูลของระบบก่อนที่จะเริ่มการประชุม
เมื่อผู้เข้าประชุม Login เข้าสู่ระบบ ระบบจะแจ้งวาระการประชุมให้ผู้เข้าประชุมทราบ และทำการแจกเอกสารไปยังผู้เข้าประชุม ตามหัวข้อวาระการประชุมต่าง ๆ เหล่านั้น ผู้เข้าประชุมจะสามารถใช้ whiteboard เพื่อเขียนหรืออธิบายงานในบางลักษณะได้ นอกจากนั้นผู้เข้าประชุมยังสามารถลงมติได้โดยประธานจะเป็นคนร้องขอให้มีการโหวดเพื่อหาข้อสรุป           ผู้เข้าประชุมสามารถแสดงผลของหน้าจอตัวเองส่งออกมาทางเครื่องโปรเจคเตอร์ได้ แต่ต้องได้รับอนุญาตจากประธานก่อน ส่วนเลขานุการนั้นสามารถเขียนบันทึกการประชุม และบันทึกข้อมูลเหล่านั้นได้ และเลขานุการสามารถรับคำสั่งจากประธานให้ทำการเปิดการลงมติได้
          เมื่อเสร็จการประชุม ระบบจะทำการบันทึกข้อมูลการประชุมทุกอย่าง เช่น บันทึกการประชุมจากเลขานุการผลการลงมติเมื่อมีการลงมติเพื่อเก็บไว้เป็นหลักฐานอ้างอิงภายหลังได้
 
 abstract  

          Nowadays,every efficiency and effective business have to start with a conference for making the best procedure because a good plan will be as a needle of a compass that will help the over all work system to be in line with together and go on the same way.
          So, this project have been created to apply computer using knowledge that we could use for solving many problems such as loss of documents,have too many useless documents.In addition,it could support a convenience of the conference,help to create and keep the conferential evidence orderly .Moreover, it could reduce the numerous paper documents and support the business more and more progressive.
          This system use at least 4 touch screen computers.Classify a type of computer according to the user;a president, a secretary,a committee and a projector.The system will save all of the documents in PDF file and it will keep the conferential file in the data base of this system before the conference will be started.
          When the users login into the system,it will inform the agenda and distribute the documents to everyone follow each of the agenda title.The users can use whiteboard for writting or explaining what they think.Moreover, the users can vote when the president allow for finding a summary.Everyone can show their own result on the moniter and send to the projector but the president have to permit first.While the secretary can record every informations and accept an order from the president when want to begin votting.
          When the conference have been finished,the system will record every conferential information ,such as a conferential record, vote result for making a reference. So,we will be able to verify in the future.
