README - tape
~~~~~~~~~~

This directory consists of signal file (.dat) to use with
file io feature of Code Composer Studio.

These signal file is used to test the operation of signal detection module: dtmfd, and r2mfd.

The sub-directory have meaning as follow:

+ [deviation] is used to test dtmfd in frequency deviation.
+ [duration] is used to test dtmfd in signal timing.
+ [int] is used to test dtmfd in signal interruption.
+ [mf] is used to test r2mf in signal timing and frequency deviation.

Remark:
The signal file stores signal in sample by sample.
