บทคัดย่อ

 

                ปริญญานิพนธ์นี้มีจุดประสงค์ในการพัฒนาระบบให้บริการแผนที่สำหรับระบบสารสนเทศภูมิศาสตร์ซึ่งมุ่งเน้นการให้บริการผ่านทางเว็บ โดยที่แผนที่ที่ให้บริการนั้นมีความสามารถในการปฏิสัมพันธ์กับผู้ใช้ได้มากกว่าแผนที่ดิจิตอลทั่วไป เช่น ผู้ใช้เรียกดูรายละเอียดของสถานที่ที่ผู้ใช้เลื่อนเมาส์ไปวางได้ การกำหนดให้แผนที่นั้นแสดงสัญลักษณ์จำพวก สี ขนาด ความหนาของเส้น การค้นหาสถานที่จากพิกัด นอกจากนี้ผู้ใช้ยังสามารถนำแผนที่ของตนเองในกรณีที่ระบบไม่มีข้อมูลแผนที่ในส่วนที่ตรงกับความต้องการของผู้ใช้มาฝากไว้เพื่อให้ระบบบริการแผนที่สำหรับระบบสารสนเทศภูมิศาสตร์มีข้อมูลตรงกับที่ผู้ใช้ต้องการ และผู้ใช้ยังสามารถเปลี่ยนแปลงและการเพิ่มข้อมูลในฐานข้อมูลของระบบตามสิทธ์ของผู้ใช้แต่ละคนได้

                ปริญญานิพนธ์นี้นำเสนอการพัฒนาแผนที่ด้วยการออกแบบและสร้างฐานข้อมูลเชิงแผนที่ และข้อมูลแผนที่ได้ถูกออกแบบให้อยู่ในรูปของเอกสาร GML (Geography Markup Language) และ SVG (Scalable Vector Graphics) โดยผู้ใช้สามารถเรียกดูข้อมูลแผนที่ทั้งรูปแบบเอกสาร GML หรือ SVG ก็ได้ และนอกจากนี้ผู้ใช้ที่ต้องการนำเข้าข้อมูลแผนที่ของตนเองยังสามารถเรียกดูข้อมูลแผนที่นั้นในรูปแบบเอกสาร SVG ได้อีกด้วย

               

               

 

 

 

 

 

 

 

 

 

 

 

 

GIS Map Service

 

                                                                                                                                                                                                                                Jirassaya Natardichard

                                                                                                                                                                                                                                Chanika  Thammati    

                                                                                                                                                                                                                                Chalita    Palaniwat    

                                                                                                                                                                                                                                Dr. Chutimed Srinilta   Advisor

                                                                        

Abstract

 

                The purpose of this thesis is to develop GIS Map Service System on the internet. The users can access the map library on this system more efficient than general digital maps. For instance, users can get the information of the places that users move the mouse over and they can also determine color, size, and stroke to the symbol which are used to represent places. They can find the places from coordinates. Not only can they add maps which are not in the system by uploading their XML-format data, but they can insert and update data in the database depending on their right also.

                This thesis has proposed a development of a system improving map services using different technologies. The map data is represented in GML and SVG format. The users can access map data in both formats. Otherwise, users can get the maps that were uploaded in SVG format.
