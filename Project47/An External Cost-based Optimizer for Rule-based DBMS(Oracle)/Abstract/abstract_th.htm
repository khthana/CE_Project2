รศ.ดร. ศุภมิตร จิตตะยโสธร อาจารย์ที่ปรึกษา
ปีการศึกษา 2547

บทคัดย่อ

    
             ในปัจจุบันมีระบบจัดการฐานข้อมูลที่เป็นแบบอิงสถิติ (Cost-Based) อยู่จำนวนมาก แต่ผู้ใช้ไม่
ทราบถึงการใช้งาน ผู้ใช้ส่วนใหญ่จะทราบเพียงวิธีการของแบบอิงกฎ (Rule-Based) ทำให้สนใจเพียงแค่ การเขียนคำสั่ง SQL ให้ดีที่สุด ซึ่งเป็นการใช้งานระบบจัดการฐานข้อมูลไม่เต็มประสิทธิภาพ นอกจากนั้น
ในการใช้ระบบจัดการฐานข้อมูลแบบอิงสถิติ จำเป็นจะต้องมีการเก็บสถิติเป็นเวลานาน
             ปริญญานิพนธ์เล่มนี้จะกล่าวถึงวิธีการ เปลี่ยนแปลงรูปแบบคำสั่ง SQL โดยพิจารณาข้อมูลทางสถิติ
ที่ได้เก็บมาเอง เพื่อให้สามารถใช้งานระบบจัดการฐานข้อมูลแบบอิงสถิติของระบบจัดการฐานข้อมูลได้
เต็มประสิทธิภาพ โดยที่ผู้ใช้โปรแกรมไม่จำเป็นต้องมีความรู้ในเรื่องระบบจัดการฐานข้อมูลแบบอิงสถิติ
และวิธีการเก็บสถิติ
