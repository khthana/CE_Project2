Abstract

                3D Reconstruction from Range Data  is the project that can construct 3D model in from object in computer. Because of picture that come from camera is 2 dimension picture.2 dimension picture is not realistic and cannot use with other application that need data of object in 3D format. 3D Reconstruction from Range Data was built to construct model of small object that model similar to original object.3D model in this project can save and use with other application .This project take picture of object by camera and use all these picture in image processing to get data that necessary to this project .Then use data to calculate the position of object. Finally   we can  get vertex data of object  that use to build 3D model.
