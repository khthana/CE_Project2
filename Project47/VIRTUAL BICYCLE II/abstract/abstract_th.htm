บทคัดย่อ

 

โครงงานการขี่รถจักรยานในสภาพแวดล้อมเสมือนจริง นั้นมีจุดประสงค์เพื่อให้ความเพลิดเพลินและเป็นเสมือนเครื่องออกกำลังกายชิ้นหนึ่งซึ่งเป็นอุปกร์อกกำลังกายที่น่าใช้กว่าการขี่จักรยานในสถานที่ออกกำลังกายเพราะว่า โครงงานขี่รถจักรยานในสภาพแวดล้อมเสมือนจริง นั้นจะไม่ใช่แค่การขี่จักรยานธรรมดาได้มีการออกแบบอุปกรณ์ให้คล้ายกับสภาวะแวดล้อมจริง มีหน้าจอเสมือนผู้ขี่กำลังมองไปในสภาวะแวดล้อมจริง โดยถ้ามีการผ่านพื้นผิวขรุขระโปรแกรมก็จะมีการสั่งงานให้จักรยานสั่น หรือถ้ามีการขี่ขึ้นเนินโปรแกรมก็จะสั่งให้ยกด้านหน้าให้สูงกว่าด้านหลังและมีการหน่วงที่เพื่อผู้ขี่ให้รู้สึกเหมือนขี่ขึ้นเนินจริงๆ โดยตัวโปรแกรมนั้นพัฒนาด้วยภาษา C++, MFC, WIN32 API ทำงานกับไลบรารี่ที่ช่วยจัดการภาพ 3 มิติอย่าง DirectX และอุปกรณ์ที่ใช้ในการสร้างสภาวะจำลองในการขับขี่นั้นถูกออกแบบและควบคุมด้วย ไมโครคอนโทรเลอร์ MCS-51 ติดต่อกับโปรแกรมบน คอมพิวเตอร์ ผ่านพอร์ตอนุกรม โดยจักรยานมีการส่งอินพุต เกี่ยวกับองศาการเลี่ยวและความเร็ว เข้ามาประมวลผล และที่ คอมพิวเตอร์ จะมีโปรแกรมจำลองสภาพแวดล้อมอยู่ ก็จะนำมาประมวลผลร่วมกับอินพุตเพื่อประมวลผลเอาพุตส่งไปที่จักรยาน แต่ว่าโครงงานนี้ก็ยังมีข้อเสียอยู่อย่างเช่น ยิ่งต้องการความเหมือนจริงมาก อุปกรณ์ก็ยิ่งมีราคาแพงการสร้างก็จะยากขึ้น ซึ่งถ้ามีงบประมาณเพียงพอโครงงานนี้น่าจะเป็นตัวเลือกของเครื่องออกกำลังกายที่ดีตัวหนึ่งเลยทีเดียว
