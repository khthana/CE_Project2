ABSTRACT

 

                There are many methods that you can identify person such as finger print detection and another method is face recognition. This project purpose to implements face detection system with Image Processing. The system has databases which contains personal face pictures when system get input from video camera system will search personal data from database and display description about person. Normally, database is very large, and time to comparison is too long so to improve system's performance we distribute database to another computer which is in network and help to search data by sending picture feature via network to another computer and report result to surveillance computer to display description about person.
