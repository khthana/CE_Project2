ABSTRACT

 

                Nowadays, trend of security system that uses biometric to authenticate user is going to be popular. It can apply to use in many security systems

                This document is about authentication system using fingerprint. The system can recognize usersí fingerprint by image processing such as Filtering, Fast Fourier Transform and Normalization. Fingerprintís character is used to compute fingercode and compared with these in the database.

                The objective of this system is to use fingerprint instead of card for authentication.
