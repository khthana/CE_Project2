บทคัดย่อ

 

โครงงานนี้นำเสนอโปรแกรมคอมพิวเตอร์ประเภทเกมในลักษณะของ Online Game Programming 2D ผ่านทางเว็บบราวเซอร์    โดยผู้เล่นเป็นผู้กำหนดท่าทาง และขั้นตอนการต่อสู้ของตัวละครในเกม   ท่าทางและขั้นตอนการต่อสู้จะแสดงในลักษณะของรูปภาพเพื่อช่วยให้ผู้เล่นเข้าใจได้ง่าย     นอกจากนั้นยังสามารถเลือกปรับท่าทางของแต่ละการต่อสู้ได้อีกด้วย ค่าพารามิเตอร์ต่างๆจะถูกส่งไปยังเซิร์ฟเวอร์เพื่อทำการประมวลผลการเล่นกับคู่ต่อสู้อีกฝ่ายหนึ่ง  

ในส่วนของการแสดงผลการเล่นจะถูกส่งมาแสดงผ่านเว็บบราวเซอร์ของผู้เล่น เกมยังเพิ่มความสนุกสนานและน่าสนใจ  โดยให้มีผู้เล่นหลายคนเข้ามาร่วมแข่งขันกัน   และมีการจัดอันดับของคะแนนเปรียบเทียบระดับผู้เล่นแต่ละคน
