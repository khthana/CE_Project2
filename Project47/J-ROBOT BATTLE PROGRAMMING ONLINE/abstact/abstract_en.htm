ABSTRACT

 

This thesis is represented a software of online game programming 2D via web browser. The player will set the posture and instructions for actor in the game. They will be shown in picture for understanding easily.

Moreover you can also change posture of the fight. Parameter will be sent to the server for processing the play of the rival. While the display of the game will be shown via web browser of the player. The game will be more fun and interesting by letting more and more people to compete and will rank points for each players.
