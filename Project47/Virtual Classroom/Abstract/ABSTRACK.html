บทคัดย่อ

        การติดต่อสื่อสารในปัจจุบันมีการพัฒนาไปอย่างรวดเร็วทำให้สื่อเข้ามามีบทบาทในชีวิตประจำวันของคนเรามากขึ้น ทั้งด้านการบริโภคข้อมูลเพื่อความบันเทิง หรือเพื่อการตัดสินใจทางธุรกิจและรวมไปถึงการเรียนรู้สิ่งต่าง ๆ ผ่านเทคโนโลยี Internet ก็ทำได้อย่างกว้างขวางขึ้น  ด้วยเหตุนี้ผู้พัฒนาจึงสร้างระบบห้องเรียนเสมือนจริงเพื่อเป็นเครื่องมือที่ใช้ช่วยในการเรียนการสอนผ่านระบบเน็ตเวิร์คที่มีอยู่ในปัจจุบัน ซึ่งเป็นโปรแกรมในการสร้างเครื่องมือในการเรียนการสอนเสมือนเราเรียนรู้อยู่ในห้องเรียน

                ในระบบห้องเรียนเสมือนจริงได้มีสองส่วนใหญ่ ๆ ที่ต้องใช้งานร่วมกันคือระบบที่เป็นเสมือนห้องเรียนซึ่งผู้สอนจะมีเครื่องมือในการสอนและตอบคำถาม ผู้เรียนจะมีเครื่องมือในการเรียนและสอบถามข้อสงสัย  ส่วนที่สองจะเป็น Web Application ที่บอกถึงกำหนดการการเรียนการสอน ประกาศ กำหนดการ ประวัติการเรียนของผู้เรียน การสมัครเรียน การ upload และ การ download เอกสารที่ใช้ประกอบการเรียนการ

ABSTRACT

Communication in present day was developed rapidly so the media is getting to involve in our routine more than those day. Both leisure use and commercial business including internet education are widely available. Therefore developer could implement a virtual classroom for user accommodation.

In virtual classroom has two major parts. First part has education applications provide knowledge including quiz application. Second part is web application provide user informations and online documents. User could register for upload and download document via this web.
