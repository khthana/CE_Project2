ABSTRACT

               

The security system and making convenient via mobile phone is system that developed to make convenient for the residents to control the home appliances. This system can make schedules for controlling devices which can automatically turn on or turn off. So it can save cost and energy for the residents

Moreover, it can examine for the security that will alert to the residents, when the emergency happened, by sending short message and turn on siren. It’s used via mobile phone or web browser that will connect to web service for sending command to control devices, viewing the device data and setting its system.
