บทคัดย่อ

เว็บเซอร์วิส คือ แอพพลิเคชันที่ ใช้เทคโนโลยี XML SOAP UDDI และ WSDL เว็บเซอร์วิสสามารถทำได้ตั้งแต่งานง่ายๆ เช่นเรียกข้อมูล จนถึงกระบวนการทางธุรกิจที่ซับซ้อน เช่น การทำรายการบัญชี เนื่องจากการเติบโตของอินเตอร์เน็ต ทำให้มีการพัฒนาด้านระบบความปลอดภัยเพื่อยืนยันตัวตนของผู้ส่งความถูกต้องและการรักษาความลับของเอกสาร ซึ่งเทคโนโลยีที่นำมาใช้งานในการพัฒนา เว็บเซอร์วิส ในวิทยานิพนธ์ฉบับนี้คือ SSL PKI และ WS-Security โดยนำ ระบบความปลอดภัย SSL มาใช้งานเมื่อฝั่งผู้เรียกใช้บริการใช้บริการจากฝั่ง SERVER และนำ ระบบความปลอดภัย PKI และ SSL มาใช้งานเมื่อมีการเรียกใช้ เว็บเซอร์วิส จาก SERVER อื่นโดยใช้เทคโนโลยี XML-Encryption และ XML-Signature วิทยานิพนธ์ฉบับนี้ศึกษาถึงวิธีในการพัฒนาเว็บเซอร์วิส โดยใช้จาวาเทคโนโลยีในการพัฒนา มีการใช้งานข้ามแฟลตฟอร์มร่วมกันระหว่าง .NET เฟรมเวิร์คด้วย และทำการเปรียบเทียบ เทคโนโลยีของทั้งสองค่าย
