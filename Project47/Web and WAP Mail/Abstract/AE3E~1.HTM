             บทคัดย่อ
                         ระบบเมล์ได้รับความสนใจเพิ่มมากขึ้นจากหลายหน่วยงาน เช่น หน่วยงานเอกชนที่ใช้เมล์เซิร์ฟเวอร์ภายในองค์กร
             การรับส่งเมล์ผ่านเมล์เซิร์ฟเวอร์ของมหาวิทยาลัยต่างๆ การส่งเมล์ผ่านทางมือถือ เป็นต้น โดยระบบเมล์ส่วนใหญ่จะไม่สามารถ
             ส่งเมล์ผ่านมือถือได้และยังไม่มีการจัดตารางนัดหมายให้กับผู้ใช้ การดักจับไวรัส ดังนั้นจำเป็นที่ต้องมีเว็บและแวบเมล์
             ที่สามารถรับเมล์และส่งเมล์ผ่านทางอินเทอร์เน็ตและมือถือได้ เพื่อช่วยอำนวยความสะดวกในการสื่อสาร ทำให้ผู้สามารถติดต่อ
             และสื่อสารสะดวกและรวดเร็วมากขึ้น
                         โครงงานนี้เป็นอีกแนวทางหนึ่งในการพัฒนาระบบเว็บและแวบเมล์ เพื่อที่จะเพิ่มประสิทธิภาพของเว็บและแวบเมล์ทั่วไป
             โดยเมล์เซิร์ฟเวอร์ที่ใช้คือ Visnetic ซึ่งเป็นฟรีแวร์ที่มีระบบป้องกันไวรัส ส่วนเว็บเมล์ที่ใช้ในการติดต่อกับเมล์เซิร์ฟเวอร์
             จะออกแบบให้สามารถรับส่งเมล์ของเมล์เซิร์ฟเวอร์ผ่านทางอินเทอร์เน็ต และมีการออกแบบตารางนัดหมายและรายชื่อบุคคล
             ที่ถูกจัดเก็บไว้ในฐานข้อมูล นอกจากนี้แวบเมล์ที่พัฒนาสามารถส่งเมล์ผ่านมือถือโดยผ่านเมล์เซิร์ฟเวอร์นี้

             Abstract
                         Recently, Mailing System was developed rapidly both performance and ability. Mailing System is used
             in many companies and networks example companies that use internal Mail Server, sending mail via
             university’s Mail Server and sending mail via mobile phone. Most of Mailing System are not support
             mailing via mobile phone.
                         This thesis is concerned with the development of Mailing System, focusing on Web and WAP Mail.
             Mail Server that use in this project is Visnetic, freeware that include anti-virus. Web Mail that contact
             with Mail Server is designed to have many applications for user requirements such as Schedule Table
             and Contact List. Web and WAP Mail will make mailing from mobile phone easier and more comfortable.
             Because we have designed this for common user, user who does not have much knowledge about
             computer or mobile phone.
