ABSTRACT

 

                This thesis presents methodology of wireless system IEEE 802.11g by MATLAB simulation (IEEE 802.11g Simulation by MATLAB) learning about wireless system IEEE 802.11g, and use results from the simulation system to improve wireless system efficiency. This project uses MATLAB because it is used for mathematic calculation. We use it to simulate methodology of wireless system.

                This thesis presents structural methodology of wireless system IEEE 802.11g, and we use the results of simulation to improve the wireless system efficiency.
