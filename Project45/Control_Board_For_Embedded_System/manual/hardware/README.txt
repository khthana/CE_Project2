คำเตือน
1.อย่านำมือที่เปียกซื้นไปจับบริเวณส่วนใดส่วนหนึ่งของ control board เพราะไม่มีการเคลือบฉนวน
2.อย่าบิดหรืองอ control board เพราะอุปกรณ์แต่ละตัวเล็กมากอาจจะมีบางตัวหลุดจาก PCB
3.ใช้แหล่งจ่ายไฟ 5.0 volt เท่านั้น ขนาดหรือเกินได้ 0.3 volt มากกว่านี้ ethenet controller อาจเสียหายได้

คำแนะนำ
1.หากบอร์ดควบคุมเปียกน้ำ จากเหงื่อ หรืออื่นๆ ให้รีบถอดแหล่งจ่ายไฟ และ ควรล้างด้วยทินเนอร์ ตากให้แห้งสนิท
2.ควรหาอุปกรณ์สำหรับ ดูดซับความซื้นเช่น สำลี เป็นต้น
3.อย่าสัมผัส Control board บริเวณที่เป็น ลายวงจรขณะมีแหล่งจ่ายไฟ
4.กดปุ่มรีเซทด้วยความระมัดระวังเพราะสวิทย์ค่อนข้างกดยาก อาจจะทำให้บอร์ดงอแล้วขาอุปกรณ์อาจจะหลุดได้

การพัฒนา
1.ออกแบบในส่วนของแหล่งจ่ายไฟผิด แต่ได้ทำการแก้ไขแล้วทั้งในตัวบอร์ดและschematic
2.ออกแบบreset ethernet controller ผิด ซึ่งปกติเป็น Active high แต่ได้ปรับปรุงแก้ไขใน บอร์ดควบคุมแล้ว
      ส่วน Schematic ยังไม่มีการแก้ไข
3.วงจรส่วนของ reset ค่อนข้างจะมีปัญหาในตอนจ่ายไฟครั้งแรก ปรับปรุงโดยใช้ IC reset ตัวอย่างใน AT91EB40 และ Inverter
