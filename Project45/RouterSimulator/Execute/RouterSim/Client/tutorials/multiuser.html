Working with client/server

 

                การทำงานแบบ Client/Server จะต้องกำหนดเครื่องใดเครื่องหนึ่งเป็น Server และ ส่วนของ Client

จะต้องเลือกการใช้งานแบบ User Mode โดยการใช้งานหลายๆเครื่องใน Designed Diagram เดียวกันนั้น

จะกำหนดสิทธิการเข้าไปคอนฟิกเราเตอร์แต่ละตัวด้วย password ภายในเราเตอร์แต่ละตัว

ซึ่ง สามารถกำหนดเอาไว้ได้ในคำสั่งของเราเตอร์เอง ดังนี้ เมื่อเปิดโปรแกรมแบบ User Mode ขึ้นมา

ปุ่มต่างๆที่ใช้สำหรับการออกแบบเครือข่ายจะถูก Disable ไปเพราะใน User Mode

ผู้ใช้มีสิทธิการใช้งานเพียงการคอนฟิกค่าเราเตอร์และทดสอบค่าต่างๆผ่านทาง Console เท่านั้น

 

หน้าจอเมื่อ Client โหลดเครือข่ายใช้งาน
