หน้าจอหลักของโปรแกรม  
  แสดงรูปโปรแกรมจำลองการทำงานเราเตอร์ซึ่งแบ่งออกเป็น 4 ส่วนได้แก่

1. ส่วนของเมนูบาร์และทูลบาร์
2. ส่วนของอุปกรณ์ที่ใช้สำหรับสร้างเครือข่ายเราเตอร์ได้แก่ เราเตอร์ สายเชื่อมต่อ และ โฮสต์
3. ส่วนแสดงสถานะของเราเตอร์
4. พื้นที่ในการสร้างเครือข่ายเราเตอร์

  
   
 

 

ส่วนของเมนูใช้งาน

  
 
ปุ่มเปิดไฟล์    ใช้สำหรับเปิดไฟล์ที่สร้างขึ้น  
 
ปุ่มโหลดไฟล์  ใช้สำหรับโหลดไฟล์ที่สร้างขึ้นโดยผู้ที่มีสถานะเป็น ผู้จัดการระบบ( administrator )  
 
ปุ่มเซฟไฟล์  ใช้สำหรับเซฟไฟล์เน็ตเวิคที่สร้างขึ้นโดยผู้จัดการระบบ ( administrator )  
 
ปุ่มลบเราเตอร์  ใช้สำหรับลบเราเตอร์ตัวที่ทำการเลือกไว้  
 
ปุ่มลบสาย  ใช้สำหรับลบสายที่เลือกไว้  
 
ปุ่มลบโฮสต์ ใช้สำหรับลบโฮสต์ที่เลือกไว้  
 
 ปุ่มแสดงรายละเอียดของเราเตอร์  ใช้แสดงจำนวนอินเทอร์เฟส ของเราเตอร์แต่ละรุ่น
 
ปุ่มแสดงบทเรียน  บทเรียนในการฝึกหัดคอนฟิกเราเตอร์
 
ปุ่มช่วยเหลือ  บอกรายละเอียดต่างๆ เช่นการใช้งานของโปรแกรม
