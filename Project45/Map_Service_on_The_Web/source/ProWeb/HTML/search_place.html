ค้นหาสถานที่สำคัญ
วิธีใช้งาน
1. เลือกประเภทของสถานที่ที่ต้องการจะค้นหา
2. ให้ใส่ชื่อของสถานที่ที่ต้องการหา เช่นต้องการหา ธนาคารไทย ก็ให้ใส่คำว่า"กรุง"หรือคำว่า"ไทย"
3. กดปุ่ม "ค้นหา" จากนั้นรอสักครู่ โปรแกรมจะแสดงชื่อของธนาคารที่มีคำว่า"กรุง"หรือ"ไทย"ขึ้นมา



   

4. ให้เลือกสถานที่ที่ต้องการจะค้นหาจากรายการที่แสดงขึ้นมา
5. กดปุ่ม"Show" โปรแกรมจะแสดงสถานที่ที่ค้นหาบนแผนที่
