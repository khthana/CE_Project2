CryptoSys (tm) API Personal Version 2.00P.

To install on your PC: click on Setup.exe
To uninstall: use the Windows Add/Remove Programs option in the Control Panel.

Files included:

* basByteUtils.txt - utilities used in the examples
* basConvert.txt - more byte utilities
* basCryptoSys.txt - the Declaration Statements module
* licence.txt - the licence text
* CLib-Borland.zip - library file for Borland C++ programmers
* CLib-MSVC.zip - library file for MSVC++ programmers
* crunset.ex_ - packed uninstall file (do not delete this file)
* CryptoSys256VB.zip - a VB demo using the 256-bit AES and SHA-256 functions
* CryptoSysManual.html - a stand-alone html manual 
* CryptoSysVBDemo.zip - a VB demo project using the hex versions of CryptoSys
* C-source.zip - test program for C/C++ programmers
* diCryptoSys.h - include file for C/C++ programmers
* diCryptoSys.lib - MSVC library file for C/C++ programmers
* Dicrypto.dl_ - packed install file
* distrib.txt - instructions for distributing with your applications
* files.lst - used by uninstall program (do not delete or edit)
* Readme.txt - this file
* Setup.exe - run once to install CryptoSys API
