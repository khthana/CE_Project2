05.10.02
--------
Another update. Due to milla's suggestions I've made some changes to the geometry of the face.
Vertices of nose, mouth and chin have been moved a little, the face should look more realistic
now. I seriously hope this doesn't bring up problems for any of you artists that already started
skinning, the new face perfectly works with my skin as well as with milla's and so it should
with yours'.

02.10.02
--------
The SDK has been updated, the model now features material groups:

1  - head, neck
2  - main body
3  - visor
4  - outer helmet, upper boots
5  - upper boosters
6  - lower booster
7  - display glow
8  - inner helmet
9  - armour, jetpack
10 - display
11 - lower boots
12 - right shoulder badge

There's also a new .jpg, colored by material groups.

Material groups will allow you to assign different shaders to different parts of the model
without breaking up the UV maps.
Thanks to milla for the info!

Ok, here it is, the SDK for my first model for Unreal Tournament 2003.


The .zip you downloaded should contain the following files:

space girl sdk.max	- the original max4 file with the model and assigned smoothing/material groups
space girl sdk.3ds	- the model exported to .3ds, please note that it got segmented during export
space girl sdk.md3	- the model exported to .md3, this format does not make use of smoothing groups
wireframe.jpg		- the unwrapped skin, white lines on black, 1024*1024
face_normals.jpg	- the unwrapped skin, colored face normals, 1024*1024
vertex_colors.jpg	- the unwrapped skin, using vertex colors, 1024*1024
material_groups.jpg	- the unwrapped skin, colored by material groups, 1024*1024
readme.txt		- the file you are reading now


This girl has a polycount of 3008, only slightly above the assumed standard polycount of 3k.
I'm going to animate her as soon as I've got a copy of UT2K3 in my hands, I'll buy the game
the day it hits the shelves here in Germany (or if that takes just too long, I'll get an import
if possible). I'll be happy to include all skins that find their way to me.
