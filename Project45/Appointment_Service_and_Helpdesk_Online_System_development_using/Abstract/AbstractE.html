Abstract

          The object of this thesis is to present the computer engineering department web development using web services. This thesis had developed 2 systems which consist of Helpdesk Online System in order to enhance computer technology knowledge service and Appointment System in order to organise time and meeting schedule in the system automatically.

          the system consist of client website and program on server which was written in PHP language and easily accesses to database, MySQL and uses Apache Web Server on Linux Operating System. The communication between client and server apply SOAP (Simple Object Access Protocal) and XML (eXtensible Markup Language) language and XML standard.

          In the thesis also describe how to operate, how to design and how to use Helpdesk Online System and Appointment System.
