ABSTRACT

 

This thesis proposes method of building 3D Game Online that is fantasy and Role Playing Game (RPG). The salient feature is method of increase efficiency in server side by using Network Load Balancing Technology. In this project we use C++, MySQL Server 4.0 and DirectX 9.0 that have Application programming interface (API) for game development.
