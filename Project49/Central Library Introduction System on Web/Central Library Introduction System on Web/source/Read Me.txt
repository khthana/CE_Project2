เนื่องจากเมื่อดับเบิ้ลคลิ้กที่ไฟล์ code ที่เป็น .xml แล้วมักจะถูกแปลงไปแสดงผลบนหน้าบราวเซอร์ ทำให้ในการเปิดดู code จากไฟลื .xml โดยตรงอาจจะยุ่งยาก 
(ต้องเปิดโปรแกรม text editer ก่อนแล้วจึงเปิดไฟล์ .xml จากโปรแกรม ถ้าดับเบิ้ลคลิ้กที่ไฟล์เลยมันจะแปลงเป็น HTML แล้ว เมื่อ view source ก็จะเห็นเป็น html เช่นกัน)

ดังนั้นจึงแปลง code เป็น pdf ดังที่เห็น โดยใช้ชื่อเดียวกับไฟล์ source ต้นฉบับ และนำหน้าด้วย [นามสกุล] เป็นรูปแบบ

[นามสกุล] ชื่อไฟล์

ถ้าต้องการดู code จากไฟล์ .xml ตัวจริง สามารถดูได้ที่โฟลเดอร์ execute แต่ต้องเปิดจาก text editer เท่านั้น (แนะนำให้เปิดจาก notepad เนื่องจากหากเปิดจาก EditPlus อาจพบปัญหาเรื่อง Font ภาษาไทย)
